## 环境

- Windows 测试机：DESKTOP-LF6684K（Windows 11），经 Tailscale（100.122.56.85）连，现在跑用户态的 denebd（m2-11090126）。我们就是经 Tailscale 连它的，Tailscale 一断就连不回去。
- Linux：本机 colima（aarch64，4 核、4 GB）里的容器。Linux 桌面虚拟机还没有。
- 要先问用户的：在 Windows 测试机上装内核网卡（先空跑检查）；下载 wintun.dll（WireGuard 官方的 wintun.net）；下载 Linux 桌面系统镜像，装进 VMware Fusion。
- 不做的：不碰 Windows 测试机上 Tailscale 的设置；不动这台 Mac 的网络、Clash、Tailscale。
