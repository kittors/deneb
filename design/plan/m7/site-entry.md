# 官网入口：/ 是首页，网页版有固定的入口

> 用户 11-16："直接访问 https://<网站>/ 应该进入首页才对啊，还有 点击 对应的logo和标题应该进入对应的官网才对的。"
>
> 截图是登录状态下的网页版，地址 /lan/<id>，红箭头指着侧栏左上角的"Deneb"。

## 1. 现在为什么不对

- **服务器**：`cmd/deneb-web/site.go` 看到登录的 cookie，就把 `/` 交给网页版，不给首页。
- **网页版**：网页版把 `/` 当成"挑第一个局域网"，马上跳过去（`web/app/src/main.ts`）。登录完也是去 `/`。
- **侧栏**：左上角的星和"Deneb"只是字，点了没反应。
- 所以登录过的人永远看不到首页，也没有路回去。

## 2. 谁、在什么情况下

| 谁 | 做什么 | 以后看到什么 |
|---|---|---|
| 没登录的人 | 打开 deneb.app | 首页，顶栏右边"使用文档 · 登录 · 下载" |
| 登录过的人 | 从书签或地址栏打开 deneb.app | 首页，顶栏"登录"的位置换成"打开网页版"，一点回到网页版 |
| 在网页版里的人 | 点侧栏左上角的星和"Deneb" | 回首页（整页打开） |
| 刚登录完的人 | 输完验证码，或点了邮件里的登录链接 | 进网页版，不是首页 |

## 3. 地址

- `/`：首页，登没登录都是。
- `/lan`：网页版的入口，按原来的规则挑一页，地址栏换成那一页的地址：
  1. 第一个局域网；
  2. 没有，就"共享给我"；
  3. 都没有，就欢迎页。
- 旧的深链接照常能用：`/lan/<id>`、`/shared`、`/mine`、`/relays`、`/share/<lan>`、`/ops`。
- 登录页的 `?next=` 照常；没有 `next` 时，登录完去 `/lan`。
- 网页版里所有"回到开头"的地方都去 `/lan`：局域网不见了（退出了、被删了）、邮件里的登录链接。

## 4. 用词（DESIGN §2.5）

- **首页顶栏，登录以后："打开网页版"**。
  - 这个按钮原来就有，只是指向 `/`，现在指向 `/lan`。
  - 它和"下载"并排：一个在网页上接着用，一个装到电脑上，两件事分得开。
  - 不叫"控制台"：那是技术词，而且运营人员看的那几页也叫控制台。
- **网页版侧栏的星和"Deneb"**：
  - 是回首页的链接，悬停时亮一层底色，和侧栏的行一样，提示能点。
  - 悬停说明写"Deneb 首页"。
- **找不到页面**：原来写"回到首页看看"，却没有链接；把"回到首页"做成链接。

## 5. 出错、没网、没登录

- **登录过期了，cookie 还在**：首页仍显示"打开网页版"（服务器只看 cookie）。点了进 `/lan`，网页版发现过期，去登录页，登完回 `/lan`。
- **没登录直接打开 `/lan`**：去登录页，登完回 `/lan`。
- **还没有局域网**：`/lan` 是欢迎页（原来就有）。
- **没网**：首页是静态页，照常显示。进了网页版，由网页版自己提示。
- 不涉及数据，没有要撤回的操作。
