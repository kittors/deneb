## 2. 怎么实现的

- **地址**（`cmd/deneb-web/site.go`）：
  - `/`：没有登录的 cookie（`proto.WebSessionCookie`），发官网首页；有，照旧发网页版（网页版自己核对，过期了照旧去登录）。
  - `/download`：下载页。`/docs`：第一篇"安装"。`/docs/<篇>`：那一篇，名字只认小写字母、数字和连字符；没有这一篇，发官网的"找不到这一页"（404）。
  - 有登录的 cookie 时，官网的页在 `<html>` 上加 `data-signed-in`，顶栏的"登录"换成"打开网页版"，不用脚本。这几页 `Cache-Control: no-cache`、`Vary: Cookie`。
  - 官网没构建时，`/` 照旧是网页版，`/download`、`/docs` 回 503 说怎么构建。
  - 别的地址照旧（网页版和它的文件；官网的样式、脚本、图在 `/site/` 下，是 dist 里的文件）。
- **构建**（`web/site/build.mjs`，没有依赖）：
  - 页面里 `{{> top}}`、`{{> foot}}` 放进共用部分，`{{here.<页>}}` 标出顶栏里当前那一项；
  - `{{pic:名字|说明}}` 是一张浅深两用的图：`<picture>`，深色时换 `dark-<名字>.webp`，带尺寸，不跳；文档里写 `![说明](名字)`，按真实大小（两倍图标成 2x）；`{{img:名字|}}` 是一张不分深浅的图；`{{dark:名字|说明}}` 只用深色那张，给深区用。
  - 文档的 Markdown 只用这几样：`# `标题，标题下面那段是一句话的说明；`1. `一步，下面缩进三格的列表、图、段落都归这一步；`## `小标题；`> `提示框；`- `列表；行内的 `代码`、**粗体**、[链接](地址)。文中的 deneb.app 包成 `.host`，部署在真域名上时脚本换成那个域名。
  - `deploy/web/build.sh` 把 `web/site` 一起拷进镜像的构建。
- **没有内联脚本**：deneb-web 的 CSP 只许本站的脚本。深浅色由 `theme.js` 在 `<head>` 里同步定（`tokens.css` 认 `data-theme`），图由 `<picture>` 跟着系统，不开 JavaScript 也能读（浅色）。
- **下载页**（`site.js`）：
  - 认系统看 UA；iPad 当 Mac 来问时，按触点数认出来。手机不出下载按钮，换成"Deneb 安装在电脑上使用。"和"复制链接"。Linux 里 UA 有 aarch64 的给 ARM64 包。
  - 下载链接都是本站的 `/download/<文件>`（nginx 直接发）。
  - 版本：读 `/download/update-darwin-arm64.json` 的 `version`，读不到不显示这一行。
  - 大小：卡片里的每个文件各发一次 HEAD，读各自的 `Content-Length`，按 Finder 的算法（1 MB = 1000000 字节），读不到不显示。
  - Linux 的卡片：两个包（窗口和后台服务）各一行，各有大小和"下载"，下面一行 `sudo apt install ./deneb.deb ./denebd.deb`（ARM64 换成 -arm64 的两个）带"复制"，和"添加设备"对话框一个写法；不出主要按钮。
  - "复制"变"已复制"2 秒，宽度不变；浏览器不让复制时选中那行命令。
- **首页的小录屏**（`[data-loop]`）：真窗口的循环（WebM 和 MP4），盖在同一张图上，开始播放才淡出来；进到眼前才播放，离开就停；右下角的暂停按钮停下和继续。开了"减弱动态效果"、省流量、或截图时只放图。第一屏的跟着系统换浅深，深区里的只有深色。循环靠最后半秒淡进开头（`design/tools/site-hero.sh`、`site-loop.py`）。
- **顶栏**：往下滚就加 `.glass`（毛玻璃）；它的中线落在深区上时标 `data-theme="dark"`，颜色 160 毫秒淡过去。
- **内容淡入**：`.reveal` 进到眼前加 `.seen`，一块里一个比一个晚 `--motion-stagger`。只在有脚本时藏起来（`theme.js` 给 `<html>` 加 `.js`），不开脚本全都在。
- **录屏**（`?record`）：虚拟时钟带着 CSS 动画、计时、滚动和小录屏走；小录屏每帧跳到那一帧的正中间，动作的步子是匀的。录屏的脚本在 `web/site/rec/<页>.js`。
- **视频**：首页先不放；照第三版重新想分镜（§4）。
- **图从哪来**：`design/tools/site-shots.sh` 跑桌面端的测试，演示数据（没有真名、真邮箱、真域名）：
  - `cmd/deneb/site_shots_test.go`、M3、M4、M6、M7、"我的设备"的场景：两倍的真界面截图；
  - `site_close_test.go`（`TestSiteCloseups`）：首页特写用的四倍截图；
  - `site_drag_test.go`（`TestSiteDragLoop`）：拖进局域网的帧和指针的位置。
  - `design/tools/site-images.py` 裁成官网和文档用的图（后面写名字就只出那几张）；`design/tools/site-loop.py <帧> drag 250,0,1180,740` 画上指针、裁掉侧边栏，做成循环。界面改了，重跑这几步。

## 3. 部署要主会话做的

- **nginx**（`deploy/web/nginx.conf.template`）：加一行 `location = /download/ { return 302 /download; }`。`/download/<文件>` 照旧由 nginx 直接发；`/download`（不带斜杠）、`/docs`、`/site/…`、`/tokens.css` 走 deneb-web。
- **下载站**：页面要的都是 `deploy/web/publish-downloads.sh` 已经放的东西，不用新的格式：
  - 固定名字的安装包：`Deneb.dmg`、`Deneb-Setup.exe`、`deneb.deb`、`denebd.deb`、`deneb-server.deb`，ARM64 的是 `deneb-arm64.deb`、`denebd-arm64.deb`、`deneb-server-arm64.deb`；HEAD 要回 `Content-Length`（nginx 默认就回）。
  - 版本：`update-darwin-arm64.json` 里的 `"version"`，发布脚本最后换的就是它。
- **上线**：照旧用户点头再做。

## 4. 视频

### 4.1 风格

全部自己做，不用别人的代码、音乐、素材和故事；页面上不署名。

| 哪里 | 我们这样做 |
| --- | --- |
| 台面 | 近黑 `#0b0c10`，上方正中提亮到 `#151821`，左上一团很淡的品牌蓝光（7%），四角压暗一半 |
| 网格 | 48 一格，白 3%，每第 4 条 6%；自己不动，只跟着镜头动 |
| 唯一的颜色 | 品牌蓝 `#4c82ff`（深色界面的蓝），光晕 `rgba(76,130,255,.35)`。连不上的红叉 `#ff5a5f` 只在开头出现 |
| 真窗口 | 每个人的颜色照旧，那是产品本身；舞台上画的东西只用品牌蓝 |
| 字 | 系统黑体；地址、端口这些"乱"的东西用等宽字 |
| 字幕 | 底部正中一枚深色半透明胶囊，1px 亮边，40 号字，左边一个品牌蓝小点；一屏一句，至少停 1.8 秒；书面语，只说事实 |
| 动作 | 24 帧；落在网格上、落在拍子上（120 拍/分）；出现 0.2 到 0.3 秒，带一点回弹；消失是缩成一点 |
| 换镜头 | 界面展开、收起，不淡入淡出，没有黑帧 |
| 声音 | 木琴、钢片琴一类加一层垫音；乱的时候散、跑调，一拖以后在同一个调上 |

### 4.3 给用户定的 6 张静帧

1. 开头：孤零零的"我的 NAS"，光走到一半。
2. 乱：断开的虚线、红叉、标签。
3. 一拖：光标拖着 NAS，乱的正在收，设备沿弧线飞进网格。
4. 揭幕：真窗口斜着转进来，光扫到一半。
5. 特写："我的设备"里服务的局域网胶囊（第 5 批的新界面）。
6. 结尾：小星、Deneb、"下载：deneb.app"。

### 4.4 怎么做（我们自己的工具）

- 真界面：桌面端的录屏测试（MyGo 的 tester，60 帧/秒，深色，两倍图）。
- 舞台：`web/site/film/stage.html`，Canvas 2D 和 CSS，按时间轴 `render(t)` 画台面、网格、光、标签、字幕，把真界面的帧放进去。
- 出片：`web/probe/record-web.mjs` 的虚拟时钟逐帧截图，ffmpeg 两个线程合成 MP4（1920×1080，H.264）和网页用的 WebM；`frame-check.py` 逐帧查。录制是重任务，要拿锁。

## 6. 没做的、要别的线做的

- 视频本身：照分镜录，拿锁，逐帧查；音乐和音效只用能商用、可署名的素材（或者自己合成），来源和许可写进说明。
- 没有屏幕的服务器怎么在命令行中登录：等引擎线给命令，"安装"一篇先写"稍后补充"。
- 桌面端"用我自己的服务器"的卡片还是 M4 的 Docker 命令，中转站安装重做以后要换；文档里没放那张卡片的图，只写"复制那一行命令"。
- 桌面端"添加设备"对话框写的是 deneb.app（`siteAddress`）；官网的文档部署在真域名上时会写真域名，两边要对上。
