## 1. 现在是什么样

### 1.1 桌面端（录屏逐帧看的）

用演示数据录，每个操作让它等 1.2 秒，像服务器在远处。60 帧每秒；画布上一直在流的光不算。

| 地方 | 按下时 | 等的时候 | 结束时 |
| --- | --- | --- | --- |
| 设置 · 软件更新 | 没反应，松开才变 | 值换成"正在检查更新"，不动 | 一帧换成"已是最新版本" |
| 同上，0.15 秒就查完 | 同上 | 字 10 帧后又换回来，一闪 | 同上 |
| 同上，查不了 | 同上 | 不动 | 设置关上，更新面板写原因 |
| 我的设备 · 刷新 | 没反应 | 变灰的"刷新中…"，不动 | 一帧换回 |
| 重命名 · 确认 | 按钮缩一下 | 按钮变灰写"保存中…"，像不能点 | 对话框收起 |
| 新建局域网（回车） | — | 输入框原样，只有光标在闪 | 输入框一帧没了，新的一行展开 |
| 加入局域网 | 有 | 原样 | 换到那个局域网 |
| 打开服务 | 有 | 原样 | 出提示条 |
| 邀请朋友 | 有 | 原样 | 出提示条"邀请链接已复制" |
| 登出 | 有 | 卡片收起后整个窗口一片白，什么都没有 | 登录页出来 |
| 导出诊断包 | 有 | 转圈"正在收集…" | 一帧换回按钮，提示条升起 |

另外：转圈有两种写法；按下时缩到 0.94、0.95、0.96、0.97 的都有；菜单行按下没反应；更新面板的按钮悬停没反应。

### 1.2 网页版（读代码盘点的，没录屏）

- 首次打开，数据回来之前整页空白，然后整个界面一下子出现。
- 不少操作等的时候完全没有表示：我的设备加入局域网、中转站不让某人用、邀请朋友、退出登录、控制台的开卡片和搜索。
- 两处转圈的写法互相覆盖：浅色下"正在看会删掉什么…"的转圈是白底白圈，看不见。
- 控制台三处第一次加载失败后，整列一直透明，像一张空白页。
- 已经有的好做法：发验证码 150 毫秒后才出"正在发…"，快的不闪。
- 动效变量只用了一处，其余时长都写死在代码里。

## 2. 谁在什么情况下等

点了一个按钮，等服务器或这台电脑上的 Deneb 答复：保存、新建、加入、打开、登出、刷新、检查更新。大多不到 1 秒，网不好时几秒，连不上时 30 秒后算失败。

| 情况 | 看到什么 |
| --- | --- |
| 很快（0.2 秒内） | 按下的样子，然后直接是结果。不出"正在…"，免得一闪 |
| 一般（0.2 秒到几秒） | 0.2 秒后，点的那个地方出转圈；结果来了，转圈先淡出，结果再淡入 |
| 很慢（几秒以上） | 转圈一直转，别的地方照常能用；对话框里的等着，不能关 |
| 出错 | 转圈换成原因（对话框里一行红字，别处出提示条），按钮回来，能再点 |
| 没网 | 和出错一样，原因写"这台电脑没联网"（DESIGN §6.10） |
| 取消 | 只有下载更新能取消；别的几秒内就完，不给取消 |

## 3. 规矩（定了以后写进 DESIGN §5）

1. 按下马上有反应：能点的东西按下都有按下的样子。块缩到 0.96；整行的（菜单行、侧栏的行）不缩，底色深一档。
2. 0.2 秒内做完的，不出"正在…"。
3. "正在…"出来了，至少留 0.4 秒，不闪一下就没。
4. "正在…"就在点的地方：按钮里，或者那一行的值的位置。不另开地方，不挡别的。
5. 算得出进度的用进度条，算不出的用转圈。
6. 结束时一次一件事：旧的先淡出，新的再淡进来（§6.5）。结果和原来一样（又查了一次，还是最新），也淡出淡入一次，让人知道查过了。
7. 等的时候按钮不变灰：变灰是"现在不能点"，等的时候是"正在做"。
8. 整页等（启动页、登出时）：灰色的星，下面一行"转圈 + 字"。

## 4. 组件（写进 design/components.md）

| 组件 | 用在 | 样子 | 参照 |
| --- | --- | --- | --- |
| 转圈 | 下面几种都用它 | 一条弧在淡色的圈上转，一秒一圈；颜色跟旁边的字，大小跟字（按钮里 16，行里 12） | HIG 的 activity indicator |

| 行里的"正在…" | 一行的值在变：软件更新、正在收集 | 值的位置：转圈 + 灰字，换值一次一件事 | HIG 的 activity indicator 配说明 |

| 整页等待 | 启动页、登出时 | 灰色的星，下面一行转圈 + 字 | — |

## 5. 微动效

只动这些，不加别的：

- 换字、换值：一次一件事。

## 7. token

加在 `cmd/deneb/theme.go`，`web/tokens/gen` 写进 `web/tokens.css`：

| 名字 | 值 | 用在 |
| --- | --- | --- |
| `busyDelay`（`--motion-busy-delay`） | 200ms | 多久以后才出"正在…" |
| `busyHold`（`--motion-busy-hold`） | 400ms | "正在…"至少留多久 |
| `spinTime`（`--motion-spin`） | 1s | 转圈一圈 |
| `swapOut`、`swapIn`（`--motion-swap-out`、`--motion-swap-in`） | 90ms、160ms | 一次一件事，原来写死在 swap.go |
| `pressGive`（`--motion-press`） | 0.96 | 按下缩到多少 |
