# M7 第 5 批：我的设备——在哪些局域网、服务、添加设备（设计稿）

> 客户端线，2026-11-14。
>
> **来由**：用户想把自己的另一台设备加进来，走不通。主会话让客户端线摸底，摸底在共享笔记 `mydevices-survey-1114.md`。用户 11-14 定了 5 件，都按推荐：
> 1. 桌面保持 Codex 的列表，往每张卡片里加"局域网胶囊""服务""加一台"三段；网页保持画布，也加这三段；列表行先不做拖到侧边栏。
> 2. 监控数字收进"详情"，卡片正面只写在不在线。
> 3. 自己加服务只填名字和端口，种类按端口猜。
> 4. 自己加的端口 TCP、UDP 都开。
> 5. 这一批不让引擎上报探到的服务。
>
> 桌面的规矩写在 DESIGN §6.15，网页的写在 §14.11。这里是从用户的角度想的每一步（AGENTS.md §1.1），还有实现要点和录屏、截图的清单。设计稿先在副本里，用户看过再进主线。

## 1. 谁、什么时候用

- **刚装好的人**：在 Mac 上装好 Deneb、登录了，家里还有一台 Windows 台式机、一台 NAS，想都连进来。他不知道"另一台怎么加"——**这是用户最初卡住的地方**。
- **想开一个服务的人**：NAS 上跑着一个网页（8080），想让"周末联机"的人能打开，"工作室"的人不行。
- **想收回的人**：游戏主机的远程桌面开给了"周末联机"，现在不想给了。

## 5. 局域网胶囊（桌面、网页一样）

**用什么组件**：多选胶囊（design/components.md），和下面"服务"那一行是同一个组件、同一种意思：带勾的是"在里面"，虚线的是"不在"。点一下就是切换。

> 为什么改：原来实心的点了是"去那个局域网"，虚线的点了是"加进去"，长得像一家、做的事不同，第一次用的人会以为点实心的会把设备移出去（主会话 11-15 指出）。现在它真的就是"移出"，和人的预期一致；去某个局域网走侧边栏，和别处一样。

- **列哪些**：我的局域网，和"成员自己带设备"的局域网；只分设备的工作室我不是拥有者时不列。顺序和侧边栏一样。
- **在里面**：品牌蓝浅底（12%）、蓝字，前面一个小勾。悬停提示"移出周末联机"。
  - 点一下：原地确认（components.md）。胶囊变成红色"再点一下，移出"；再点才移出（`lan.removeDevice`），提示条"已将我的 NAS 移出周末联机 · 撤销"。指针离开、或 4 秒不点，就变回去。
  - 要确认，是因为局域网里的人会因此用不了它；撤得回来，所以只确认一次、不用对话框。
- **不在里面**：1.5px 虚线、灰字。悬停提示"加入工作室"，描边和字变蓝。
  - 点一下就加入（`lan.addDevice`），提示条"已将我的 NAS 加入工作室 · 撤销"。
- **要拥有者同意的**：加入以后是蓝色虚线，名字后面灰字"等待同意"；提示条"我的 NAS 正在等待阿杰同意 · 撤销"。再点一下就撤回请求（不用确认，提示条能撤销）。悬停提示"等待阿杰同意，点按撤回"。
- **这台电脑**：在里面的局域网照样带勾，但点不动，样子也是点不动的：中性灰底、灰勾灰字，没有悬停态、指针不变手形、不按下；悬停提示"正在使用的这台电脑不能移出"（DESIGN §6.2）。
- **出错**：提示条照服务器的话说（位置满了之类），胶囊回到原样。
- **没有局域网**：这一行灰字"暂无局域网"。
- **很多**：一行放不下就折到下一行。
- **名字很长**：胶囊最宽 220，放不下的用省略号，悬停提示里是全名。

## 6. 服务（桌面、网页一样）

- **一项一行**：图标、名字（同名的后面带端口，Codex 的 `serviceLabel`；最多两行），后面一排多选胶囊，是这台设备所在的每个局域网。和上面"局域网"那一行同一个组件。
  - 开着：品牌蓝浅底、蓝字、小勾。悬停提示"在周末联机关闭"。
  - 关着：虚线、灰字。悬停提示"开放给周末联机"。
  - 点一下就开（`service.set`），和局域网画布上设备卡片里的开关是同一份，两边一起变。
  - 关：原地确认，胶囊变成红色"再点一下，关闭"，再点才关。原来用对话框，components.md 说能在原地确认的不弹对话框。
  - 第一次开"命令行"时，那一行下面出一行灰字："开放命令行后，对方可以经这台电脑访问其他地方，请只开放给信任的人。"5 秒后淡掉（文末第 4 条）。
- **这台电脑**：还没开放、但本机探到的服务（远程桌面、共享文件夹、命令行、网站这几种常见端口）也列出来，胶囊都是虚线。
- **设备不在任何局域网**：这一块只有一行灰字"加入局域网后可开放服务"，没有"添加服务"。服务器的 `service.set` 要设备在那个局域网里。
- **不在线的设备**：照样能设，它上线就照这样开。
- **一项都没有**：灰字"暂无服务"，下面是"+ 添加服务"。

### 6.1 添加服务

- 最后一行是一枚虚线小胶囊"+ 添加服务"。点了，原地展开成一行（高度平滑）：
  - 名称输入框（灰字"名称"，宽 200）；
  - 端口输入框（灰字"端口"，宽 84，只收数字；不放"8080"这样的示例，免得看着像已经填好了）；
  - 主要按钮"添加"（没填端口时变淡、点不动）、文字按钮"取消"。
  - 名称框自动聚焦；回车就是"添加"，Esc 就是"取消"。
- **种类按端口猜**（猜不到就是"其他"）：

  | 端口 | 种类 |
  | --- | --- |
  | 3389、5900 | 远程桌面 |
  | 445、548、139 | 共享文件夹 |
  | 22 | 命令行 |
  | 80、443、3000、5000、8000、8080、8443、8888 | 网站 |
  | 25565、27015、7777、19132 | 游戏 |

- **名称空着**：用猜出来的种类名（"网站"）；"其他"空着叫"服务"。
- **开哪些端口**：TCP 和 UDP 都开（用户定的第 4 条）。
- **添加以后**：
  - 新的一行长出来，胶囊都是虚线，谁也不公开；
  - 提示条"已添加「我的网站」 · 撤销"，撤销就是删掉它；
  - 原来下面还有一行灰字"点局域网的名字，就开给它"，按新规矩删了：胶囊的悬停提示已经说了（AGENTS.md §2.5，解释放 tooltip）。
  - 服务器那边：在这台设备所在的第一个局域网里，用 `service.set` 带整份服务、关着，建进目录。
- **出错**：在输入框下面一行红字，输入框不清空，光标回到出错的那个框：
  - 端口不是 1 到 65535："端口应为 1–65535 之间的数字"
  - 这个端口已经有服务在用（服务器回的）："端口 8080 已被「网站」占用"
  - 连不上服务器："未能添加：无法连接服务器，请重试"
  - 名称最多 40 个字，再长就打不进去。

### 6.2 删除服务

- 悬停那一行，最右边露出一个小"×"，悬停提示"删除我的网站"。
- 点了，原地确认："×"变成红色"再点一下，删除"；再点才删。指针离开或 4 秒不点就变回去。
- 删除后那一行收起（高度平滑），提示条"已删除「我的网站」"。已经确认过，就不再给撤销（文末第 3 条）。服务器那边是 `service.remove`。
- 本机探到、还没进目录的那几项没有"×"。

## 7. 添加设备

- **组件**：对话框（design/components.md：一件要专心做完的事）。
  - 桌面：居中弹窗，和设置弹窗一个样子，宽 480（Linux 那行命令要一行放下，折成两行会被当成两条命令）；
  - 网页：右上角卡片，和设备卡片同一层，宽 300。
- **标题**"添加设备"，下面直接是三步。原来标题下还有一句"装上 Deneb、用同一个邮箱登录，它就会自己出现在这里"，和三步说的是同一件事，删了。
- **三步**，前面是品牌蓝的小圆数字（24），对着每一步的第一行：
  1. "在另一台电脑上打开 deneb.app"，右边文字按钮"复制网址"，点了变"已复制"，2 秒后变回来。
  2. "下载并安装 Deneb"。下面一枚文字按钮"首次打开时被系统阻止"，点了展开三段（高度平滑）：
     - Mac："打开「系统设置」>「隐私与安全」，在「安全性」中点按「仍要打开」，再输入登录密码。"（名字照 macOS 27.0.1 简体中文系统里实际显示的核对过：系统设置、隐私与安全、安全性、仍要打开。）
     - Windows："出现「Windows 已保护你的电脑」时，点「更多信息」，再点「仍要运行」。"
     - Linux："需同时安装 deneb.deb 和 denebd.deb（后台服务）。在下载目录中运行："，下面一块等宽字 `sudo apt install ./deneb.deb ./denebd.deb`，右边文字按钮"复制"。网页卡片窄，命令写成两行续行（第一行末尾"\"），复制的是一行的。
  3. "使用 a•••@example.com 登录"（邮箱打码，和网页的 `maskEmail` 一样；不知道邮箱时"使用同一邮箱登录"）。
- **网页多一行**：第 1 步下面"这台电脑："，后面文字按钮"下载 macOS 版"（按认出的系统写）。
- **等待**：最下面一行灰字，前面一个小转圈："等待设备上线…"。
- **到了**：
  - 对话框开着：第 3 步前面换成绿勾，那一行变成"MacBook 已加入"，"等待设备上线…"原地淡掉；1.2 秒后对话框自己收起，列表平滑滑到那张新卡片（不在眼前时；Smooth），它亮一下（淡蓝底，1.2 秒退掉）。网页上卡片收起以后，新设备才从画布边上飞进来，落在"添加设备"原来的位置（Bouncy），"添加设备"先让到不挡的地方（Smooth）；卡片开着时不飞，免得从卡片底下穿过去（§6.3）。
  - 对话框关着：提示条"MacBook 已加入"（没有撤销），新卡片照样亮一下；列表不自己滚（用户可能正在别处做事，比如正在填服务）。
  - "到了"指这个账号多了一台设备：打开对话框时记下有哪几台，后来多出来的就是。
- **复制不了**（剪贴板不让用）：那枚按钮换成网址本身，可以选中。
- **关掉**：右上角"×"、Esc、点外面都行。关掉不影响什么，到了时照样有提示条。
- **安装包的名字**：0.1.8 以后，下载站上是固定的 Deneb.dmg、Deneb-Setup.exe、deneb.deb、denebd.deb。对话框不直接给下载链接（那台电脑上才用得着），只说去 deneb.app。

## 8. 用词（DESIGN §2、AGENTS.md §2.5）

## 9. 实现要点（看过再做）

- **客户端模型**（`client/model`）：
  - `Op` 加一个 `Def`（整份服务：种类、名字、端口），`service.set` 碰到目录里还没有的服务时用它；
  - 加 `OpServiceRemove`（Device、Service）。
  - 演示（`client/demo.go`）要支持：新服务、删服务、"另一台电脑登录了"（录屏用）。
- **真客户端**（`client/live.go`）：
  - `service.set` 按编号查不到时用 `Def`；
  - `service.remove` 发目录里那份整的服务。
- **桌面**（`cmd/deneb`）：
  - `mydevices.go`：卡片三段，详情收进监控数字，标题区"+ 添加设备"；
  - 新文件放"添加设备"对话框；
  - 端口猜种类的表放在 `client/model`，网页的 `model.ts` 照抄一份。
- **网页**：
  - `mine.ts`：卡片的服务一块、画布上的"添加设备"虚线块和卡片；
  - `model.ts`：加 `service.remove`；
  - 假服务器（`cmd/deneb-web/mock.go`）：支持 `service.remove` 和新服务。
- **服务器**：不用改。`service.set` 第一次就把服务建进目录，`service.remove` Codex 已经加了。

## 9.5 按设计体系改了什么（AGENTS.md §2，11-15）
