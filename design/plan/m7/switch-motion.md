## 1. 现在是什么样（录屏逐帧看的）

用测试器录真窗口，每秒 60 帧，1180×740，浅色、深色各一遍，用 `design/tools/frame-check.py` 找跳变。演示数据里把"我的游戏主机"也加进了工作室，所以两个局域网共有"这台电脑"和游戏主机，游戏主机在两边的位置不同。用户说的"同一台 DESKTOP"就是这种情况。

| 操作 | 逐帧看到的 |
| --- | --- |
| 局域网 → 局域网 | 第 63 帧一帧换完：标题、那句话、画布上所有设备和连线、侧栏的白底，都在这一帧换掉。游戏主机从左下一下跳到右下。之后 10 帧还有两处在动：<br>· 标题右边的小球：旧的滑到"邀请朋友"底下，被按钮压着淡掉；<br>· 托盘：先露出一个空的灰格子，再收拢。 |
| 局域网 ↔ 全部 | 一帧换完，之后什么都不动。托盘一帧没了，"这台电脑"的名字从下面一帧跳到上面。 |
| 画布 ↔ 我的设备、共享给我 | 一帧换完。 |
| 连着快速点四次 | 每点一下就一帧换完。不叠也不卡，但每一下都是硬切。 |
| 侧栏的行 | 悬停的底色一帧出现、一帧消失；按下没有反应。 |
| 局域网那一行的开关 | 圆钮滑动、颜色渐变都在，但按下没有反应。<br>关上（暂停）的那一帧里同时发生三件事：<br>· 线里的光一下没了；<br>· 每台设备下面那行字一下从"直接连上"变成"已暂停"；<br>· 中转站的名字一下没了，球还在慢慢缩。<br>再打开时，中转站连名字一帧冒出来。 |

## 2. 谁在什么情况下切换

在两个以上局域网里的人：看这个局域网的设备，再去看那个；去"我的设备"管自己的设备，再回来；看别人分给我的。切换只换窗口里看到的东西，连接一条都不动（`show` 原来就这样）。

| 情况 | 看到什么 |
| --- | --- |
| 一般 | 点下去侧栏那一行底色深一档。松开后白底滑过去；旧页面独有的东西 0.09 秒淡出，新页面独有的东西接着 0.16 秒淡入；两边都有的设备滑到新位置，连线跟着走，光照常流。大约 0.4 秒停稳。 |
| 连着快速点 | 每一下都从现在的样子接着走：<br>· 走到一半的设备直接拐向新目标，速度不断；<br>· 淡到一半的东西从那个深浅往回淡，不会先跳回全亮；<br>· 标题一次只有一个，中间点过的局域网名字不会闪出来。<br>不叠、不抖、不卡。 |
| 电脑很慢、掉帧 | 弹簧和淡入淡出按时间走，掉了帧也按时到，不会补放。 |
| 系统开了"减弱动态效果" | 位置直接到，只留淡入淡出（DESIGN §5）。 |
| 切换时卡片开着 | 卡片收起，同时切换。 |
| 切换时提示条在 | 提示条照它原来的样子退场，它压着没发的操作照常发出去（原来就这样）。 |
| 切换时手里拖着东西 | 侧栏点不到，不会切换。 |
| 正看着的局域网在别处被删了 | 画面去第一个局域网，同样淡出淡入。原型里这一种还是一下换掉，实现时补上。 |
| 没网、出错 | 切换只读这台电脑上已有的数据，不会因为没网失败；没网时设备下面照常写"这台电脑没联网…"（§6.10）。 |

## 3. 怎么过渡

### 3.1 一条规矩：留下的移过去，其余一次一件事

- **两边都有的**（这台电脑、同一台设备、同一个中转站）：留在画面上，用 Smooth 弹簧移到新位置，连线跟着它走，线里的光不断。
  - 认法是同一台设备、同一个局域网优先；没有的话，同一台设备从别的局域网过来。
  - 所以从"全部"进某个局域网时，那块区域里的设备走到局域网画布上的位置；反过来走回区域里。
- **只有旧页面有的**：在原地淡出，用 `swapOut`（90 毫秒），它的线跟着淡。不缩小，因为缩小是"离开了局域网"的样子（§6.4）。
- **只有新页面有的**：等 `swapOut` 让旧的先走，再用 `swapIn`（160 毫秒）淡入。不弹，也不从"这台电脑"长出线，那是"刚加入"的样子（场景 3）。
- **标题、标题下面那句话、标题右边的小球**：一次一件事，旧的淡出，新的再淡入（§6.5）。"邀请朋友"两边都有就不动；只有一边有，就跟着小球淡出淡入。
- **侧栏的白底**：从上一行滑到这一行（Smooth），在字的底下。滑到以后交回给那一行，前后像素不变。

### 3.2 每一种切换

| 从 → 到 | 怎么过渡 |
| --- | --- |
| 局域网 → 局域网 | 按 §3.1。<br>· 托盘：只有旧页面有的格子，设备块在格子里淡出，格子跟着收拢，不露空格子；两边都有的格子不动。<br>· 中转站：两边都显示的就移过去，否则淡出、淡入。 |
| 局域网 ↔ 全部 | 设备走进或走出各自的区域。<br>· 区域的底色和名字在原地淡入淡出，不从下面升上来。<br>· "这台电脑"在"全部"里名字在上面，在局域网里在下面：先在原处淡出，换到另一边再淡入，不从设备块上穿过。下面那行字跟着名字一起换。<br>· 托盘在原地淡出淡入，不下沉、不上升。 |
| 画布 ↔ 我的设备 | 整页一次一件事：画布页（连标题区）淡出，"我的设备"页再淡入。两页没有共同的东西可以留，不做别的。 |
| 局域网 ↔ 共享给我 | 和局域网之间一样："这台电脑"移过去，其余淡出淡入。 |
| 第一次打开窗口 | 不做过渡，直接是上次看的那一页。 |

### 3.3 侧栏的行

| 状态 | 样子 |
| --- | --- |
| 悬停 | 底色 160 毫秒淡入、淡出（`fadeTime`）。 |
| 按下 | 底色深一档，行本身不缩，和第 13 批的菜单行一样（`well` 混 8% 的 `ink`）。 |
| 选中 | 白底滑过来；名字 160 毫秒变成深色。 |
| 选中那一刻 | 原来这一行的悬停底色立刻去掉，等白底滑到，不在白底上叠一层灰。 |

### 3.4 局域网那一行的开关

| 时刻 | 样子 |
| --- | --- |
| 按下 | 圆钮朝要去的方向拉长 3，用 160 毫秒，HIG 开关的做法。原来按下没有反应。 |
| 拨动 | 圆钮 Snappy 滑过去，底色渐变（原来就有）。 |
| 关上时的画布 | 照场景 3 的设计：线退回这台电脑，原处留一排点，设备变灰。原型里改了三处原来一帧完成的：<br>· 线里的光 160 毫秒淡掉；<br>· 设备下面那行字一次一句；<br>· 中转站的名字跟着球一起淡掉。 |
| 打开时的画布 | 中转站连名字一帧冒出来，原因还没查清。实现时让它照原来的设计弹出来。 |

### 3.5 不做的

- 不做页面整体滑动、缩放、翻页这类转场。窗口里只有内容在换，侧栏不动，滑动会让人以为去了别处。
- 只有新页面有的设备不做依次出现（stagger）。设备多时会拖长，用户还没看清就在等。
- 设备移动走直线，不走弧线。

## 4. 用到的动效 token

不加新的时长，都用已有的：

| 用在 | token | 值 |
| --- | --- | --- |
| 留下的东西移动、侧栏白底 | `ui.Smooth` | 弹簧 500ms，不回弹 |
| 旧的淡出 | `swapOut` | 90ms |
| 新的淡入（等 `swapOut` 后） | `swapIn` | 160ms |
| 悬停、按下底色、名字变深、开关按下 | `fadeTime` | 160ms EaseOut |

`swapOut`、`swapIn` 现在写在 `swap.go`，第 13 批的原型把它们挪进了 `theme.go`，成了 token。

两个新值，定了以后加进 token：
- **开关按下时圆钮拉长 3**：`switchStretch`。
- **按下的底色**：和第 13 批共用一个，第 13 批原型里写成 `well.Mix(ink, 0.08)`。建议两批合并时加进调色板（例如 `pressed`），先合的那批加。

定了以后，§3 的规矩写进 DESIGN §5，组件写进 `design/components.md`（这批已经先写了，标着"待用户定"）。

## 5. 局域网头像

### 5.1 三套候选

都是可爱风格的表情图，一套 16 个：猫、狗、狐狸、熊猫、兔子、青蛙、企鹅、鲸鱼、蘑菇、仙人掌、彩虹、土星、游戏手柄、房子、向日葵、火箭。都在真界面里截了图：侧栏 20、标题旁 28，浅色、深色各一份。

| | 甲 · Fluent 3D | 乙 · Fluent 3D 加底色 | 丙 · Noto |
| --- | --- | --- | --- |
| 样子 | 立体、圆润，有光泽 | 和甲同一套图，放在一个淡色的圆角方块里 | 平面，带描边 |
| 和 Deneb 放在一起 | 和设备块的光泽、设备头像预设的瓷质小物件最像 | 像应用图标；侧栏里每个局域网都多一块颜色，整齐但更花 | 线条最清楚，但比设备块平，风格差一截 |
| 小尺寸（20） | 看得清 | 图只剩 15，略小 | 最清楚 |
| 许可 | MIT（微软 fluentui-emoji） | MIT | Apache 2.0（googlefonts/noto-emoji 的图片；字体本身是 OFL，不用） |
| 要做的 | 把 MIT 的版权声明写进 `THIRD_PARTY_NOTICES` | 同甲 | 把 Apache 2.0 许可写进 `THIRD_PARTY_NOTICES` |

**推荐甲**：最可爱，和设备块的立体感一致，许可最干净。上传的照片裁成圆角方块，和不加底的表情放在一起也不乱，Notion 的页面图标就是这样。

没做"照 Deneb 设备图标的风格自己画一组"。那要画 16 个可爱的小物件，小尺寸还得单独调，一两天的量，画不好会显得廉价。用户想要完全自己的图，再单独做。

### 5.3 怎么换

- **新建局域网时**：自动从这一套里随机给一个，存到服务器上，所以每个人、每台设备看到的都一样。
- **拥有者换**：点标题旁的头像，或者在局域网卡片里点"换头像"，打开"局域网头像"对话框。和设备头像的对话框是同一个结构：
  - 上面是现在的头像 64、局域网名字、"上传图片"、一行灰字"PNG / JPEG · 最大 8 MB"；
  - 下面两行 16 个，选中的带蓝框；
  - 右下"取消""保存"。
- **上传自己的图**：照设备头像的做法。先在这台电脑上从中间裁成 128×128 的 PNG，重新编码一遍，照片里的拍摄信息就去掉了，再上传。服务器收到后再做一遍。
- **成员**：只能看，点头像打开的卡片里没有"换头像"。
- **恢复默认**：选回这一套里的任何一个就是。不另设"恢复默认"按钮。

| 出错 | 看到什么 |
| --- | --- |
| 图太大、不是 PNG/JPEG | 对话框里一行红字，和设备头像一样："图片不能超过 8 MB""请选择 PNG 或 JPEG 图片" |
| 没网、服务器连不上 | 第 13 批的"按钮里的进行中"；失败后红字"这台电脑没联网"或连不上的原因，可以再点"保存" |
| 不是拥有者（别处改了拥有者） | 红字"只有拥有者能换头像"，对话框不关 |
| 撤回 | 换错了再换回来就行。没有危险，不用再确认一次。 |

### 5.4 服务器那一半（控制线做，主会话协调）

- **存**：局域网多一个 `icon`。
  - 预设：`{"preset": "fluent3d/cat"}`；
  - 上传：`{"image": <128×128 PNG>}`。
  - 新建局域网时服务器从预设里随机挑一个写进去，老局域网第一次读到时也补一个。
- **改**：新的 op `lan.setIcon`。
  - 参数：`lan`，加上 `preset` 或 `image` 二选一。
  - 只有拥有者能改。
  - 图片用和 `proto.NormalizeDeviceAvatar` 同样的规则处理：最大 8 MB，只收 PNG/JPEG，从中间裁成 128×128 的 PNG 再存。建议把这个函数改个名字给两边共用。
- **读**：成员拿到的局域网视图里带 `icon`。
  - 预设只带名字；
  - 上传的图带 PNG，或者给地址加内容哈希，免得每次网络图都带一张图。控制线定。
  - 邀请链接的预览（`/api/v1/invites/<token>`）也带 `icon`，邀请页要显示。
- **功能开关**：`lanIcon`。服务器没有这个功能时，客户端照旧显示成员小球。
- **隐私**：`PRIVACY.md`（英文）加一句：局域网头像存在控制服务器上，局域网的成员和拿到邀请链接的人看得到；删掉局域网时一起删掉。

### 5.5 许可

- 选甲或乙：仓库里放 16 张 PNG。桌面端嵌进程序，网页放在静态资源里。`THIRD_PARTY_NOTICES` 写 fluentui-emoji 的 MIT 声明。
- 选丙：放 PNG，写 Apache 2.0 的许可全文和出处。

三套候选的图现在只在交付文件夹里。用户选定那一套以后再放进仓库，桌面端放 `cmd/deneb/lan-icons/`。
