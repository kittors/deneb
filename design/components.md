# 组件和语义

> AGENTS.md §2.2：按场景和语义选组件，不按长相选。语义参照 Apple HIG、Radix、Material。这里是第一版，按现有界面整理；审查产品时，把截图范例补进各节。

## 按钮 Button

| 种类 | 用在 | 例子 |
| --- | --- | --- |
| 主要（实心胶囊，`primary`） | 这一块最主要的那个动作，一块只放一个 | 邀请朋友、保存 |
| 次要（白底描边） | 和主要并列的其他动作 | 取消、稍后 |
| 文字按钮 | 不抢眼的动作、跳转 | 看全部、去看、复制 |
| 危险 | 删除、注销这类改不回来的动作 | 删除这台设备 |

- **Do**：
  - 按钮上写动词，说清点了会怎样。
  - 危险操作的入口用红色文字按钮；到最后确认那一步，才用红色实心。
- **Don't**：
  - 两个主要按钮并排。
  - 用主要按钮做"取消"。
  - 用胶囊标签当按钮。

## 开关 Switch

用在：只有开和关两种状态、拨了马上生效的设置，比如局域网开关、服务开关。

- **Don't**：
  - 用开关触发一个动作，比如"立即同步"。
  - 拨完还要再点"保存"。

## 分段控件 Segmented control

用在：同一块内容的几种看法之间切换，比如运营记录 / 服务器日志，浅色 / 深色 / 跟随系统。

- **Don't**：
  - 用它在页面之间跳转，那是侧边栏的事。
  - 用它做能叠加的筛选，那用筛选胶囊。

## 筛选胶囊 Filter chip

用在：筛一张列表，比如全部、在线、不在线、登出了。

- **Don't**：
  - 拿它显示状态。
  - 拿它执行操作。

## 状态标签 Badge

用在：只读的状态和计数，比如侧边栏后面的数字、设备的"在线"。

- **Don't**：做成能点的。要能点，就是按钮或 alert。

## 弹出卡片 Popover

用在：看选中的那个东西的详情和相关操作，比如设备卡片、人物卡片、中转站卡片。

- 从右上角长出来，不挡住正在操作的东西，旁边的内容让出位置（DESIGN.md §4）。
- 不是模态的：卡片外面照样能操作。点 ×、按 Esc 或点别处就关。

**Don't**：用对话框显示详情。

## 对话框 Dialog

用在：必须先做决定才能继续，而且这个决定分量重，比如改名字、换头像。

- 内容只有三样：一个标题、最多一句话、"取消"加一个主要按钮。

- **Don't**：
  - 能在原地确认的事，弹对话框。
  - 用对话框通知一件事。

## 原地确认 Inline confirm

用在：有风险、但撤得回来，或者影响面小的操作，比如删设备、撤管理员。按钮原地变成"再点一下，删掉"。

- 改不回来、影响又大的（注销账号），才要求输入确认，比如输对方的邮箱。

## 提示条 Toast

用在：报告一件已经做完的事，几秒后自己消失。撤得回来的，带"撤销"。

- **Don't**：
  - 报需要用户处理的问题，那用 alert。
  - 放长句子。

## 警示 Alert

用在：需要用户处理的问题，比如本地网络权限没拿到、引擎没更新、服务器报警。

- 问题不解决就一直在。一句话说清是什么，再给一个去处理的动作。

**Don't**：报成功，或者放小贴士。

## 工具提示 Tooltip

用在：不常看的解释和细节，比如毫秒数、地址、某个词是什么意思。悬停或键盘聚焦时出现。

**Don't**：把必需的信息或操作藏在里面，触控板和触屏用户可能看不到。

## 输入框 Input

用在：只能靠打字的地方，比如名字、端口、确认邮箱。

**Don't**：能拖、能点完成的事，做成表单。

## 导航行 Nav row

侧边栏的一行：图标、名字，后面是计数或开关；选中时有底色。只用于导航到一个页面，或者开关一个局域网。

## 空状态 Empty state

用在：还没有内容的时候。说一句这里放什么，再给一个下一步，比如"+ 加一台"。

**Don't**：留白，或者写一段话。

## 小球 Avatar

用在：一个人，显示首字加主人色。

**Don't**：拿它表示状态。

## 设备块 Device tile

画布上的一台设备，见 DESIGN.md §3.4。只表示设备，不拿来当按钮用。

## 进度 Progress

用在：超过一秒的事，比如下载更新、导出诊断包。能算出比例的显示比例，算不出的只显示在进行中。
