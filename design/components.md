# 组件和语义

> AGENTS.md §2.2：按场景和语义选组件，不按长相选。语义参照 Apple HIG、Radix、Material。这里是第一版，按现有界面整理；审查产品时，把截图范例补进各节。

## 按钮 Button

| 种类 | 用在 | 例子 |
| --- | --- | --- |
| 主要（实心胶囊，`primary`） | 这一块最主要的那个动作，一块只放一个 | 邀请朋友、保存 |
| 次要（白底描边） | 和主要并列的其他动作 | 取消、稍后 |
| 文字按钮 | 不抢眼的动作、跳转 | 看全部、去看、复制 |
| 危险 | 删除、注销这类改不回来的动作 | 删除这台设备 |

- **Do**：
  - 按钮上写动词，说清点了会怎样。
  - 危险操作的入口用红色文字按钮；到最后确认那一步，才用红色实心。
- **Don't**：
  - 两个主要按钮并排。
  - 用主要按钮做"取消"。
  - 用胶囊标签当按钮。
- **大小**（第9批统一）：
  - 对话框里用 `dialogButton`：高 40，左右 16。
  - 卡片里用 `cardPrimary` 和 `ghostButton`：高 34，左右 16，13 号字。
  - 灰底的框里用 `wellButton`：白色、带一点阴影，高 28、左右 12（服务的"打开"、菜单栏小窗的"同意"、注销以后的"复制"）。**Don't**：在灰底上放灰色的 `ghostButton`，它看不出是个按钮，字像飘在框里。
  - 文字按钮（更多、导出诊断包、删除这台设备）的底色向外伸，字留在边上（内边距加等量的负外边距）。在居中的页面里（启动页），它跟着居中，不向外伸。
- **按下**：按钮这样的块缩到 0.96（`pressGive`）；整行的（菜单行、侧栏的行）不缩，底色换成 `press`（`well` 往字色混 8%）。悬停的底色 160 毫秒淡变（`fadeTime`）。
- **要等的按钮**：`dialogButton`、`primaryButton`（`cardPrimary`、`onboardButton`）、`textButton`、`wellButton` 都可以带上它发起的事（`busy`），等的时候照"进行中"一节做，不用另写。

## 开关 Switch

用在：单独一项、只有开和关、拨了马上生效的设置，比如局域网开关。

- **Don't**：
  - 用开关触发一个动作，比如"立即同步"。
  - 拨完还要再点"保存"。

## 多选胶囊 Toggle chip

用在：从几个选项里选几个，选了马上生效。比如一项服务开给哪几个局域网：选中的实心带勾，没选的是虚线。

**Don't**：只有一个选项时用它，那用开关。

## 分段控件 Segmented control

用在：同一块内容的几种看法之间切换，比如运营记录 / 服务器日志，浅色 / 深色 / 跟随系统。

- **Don't**：
  - 用它在页面之间跳转，那是侧边栏的事。
  - 用它做能叠加的筛选，那用筛选胶囊。

## 筛选胶囊 Filter chip

用在：筛一张列表，比如全部、在线、不在线、登出了。

- **Don't**：
  - 拿它显示状态。
  - 拿它执行操作。

## 状态标签 Badge

用在：只读的状态和计数，比如侧边栏后面的数字、设备的"在线"。

- **Don't**：做成能点的。要能点，就是按钮或 alert。

## 弹出卡片 Popover

用在：看选中的那个东西的详情和相关操作，比如设备卡片、人物卡片、中转站卡片。

- 从右上角长出来，不挡住正在操作的东西，旁边的内容让出位置（DESIGN.md §4）。
- 不是模态的：卡片外面照样能操作。点 ×、按 Esc 或点别处就关。

**Don't**：用对话框显示详情。

## 对话框 Dialog

用在两种情况：
- 一件要专心做完的事，比如加一台设备、换头像；
- 必须先做决定才能继续，而且这个决定分量重，比如改名字。

内容只有一个标题、要做的事本身、最多一句话，按钮放在右下。

- `modalPanel`：四周内边距 24。关闭用图标按钮，向外伸 8，× 的右边和内容的右边对齐。
- 按钮用 `dialogActions` 排：靠右，之间 12。

- **Don't**：
  - 能在原地确认的事，弹对话框。
  - 用对话框通知一件事。

## 原地确认 Inline confirm

用在：有风险、但撤得回来，或者影响面小的操作，比如删设备、撤管理员。按钮原地变成"再点一下，删掉"。

- 改不回来、影响又大的（注销账号），才要求输入确认，比如输对方的邮箱。

## 提示条 Toast

用在：报告一件已经做完的事，几秒后自己消失。撤得回来的，带"撤销"。

- **Don't**：
  - 报需要用户处理的问题，那用 alert。
  - 放长句子。

## 警示 Alert

用在：需要用户处理的问题，比如本地网络权限没拿到、引擎没更新、服务器报警。

- 问题不解决就一直在。一句话说清是什么，再给一个去处理的动作。

**Don't**：报成功，或者放小贴士。

## 工具提示 Tooltip

用在：不常看的解释和细节，比如毫秒数、地址、某个词是什么意思。悬停或键盘聚焦时出现。

**Don't**：把必需的信息或操作藏在里面，触控板和触屏用户可能看不到。

## 输入框 Input

用在：只能靠打字的地方，比如名字、端口、确认邮箱。

**Don't**：能拖、能点完成的事，做成表单。

## 导航行 Nav row

侧边栏的一行：图标、名字，后面是计数或开关；选中时有底色。只用于导航到一个页面，或者开关一个局域网。

- 左右 8，图标和名字之间 12。图标、组名、星标、账号头像的左边在一条线上。

## 菜单行 Menu row

`menuItem`：卡片、设置里一行就是一个按钮。左边是名字，右边是它现在的值（灰色，"名称：值"），再右边是图标。

- 底色伸到卡片边上，字留在内容的左边。
- 悬停时底色是 `well`，按下时换成 `press`，都淡变 160 毫秒；整行不缩。
- **Do**：把这一项现在的情况写成右边的值，比如"软件更新　已是最新版本"。
- **Don't**：把值另起一行放在下面，它会像单独的一行。

## 图标按钮 Icon button

`iconButton`：只有图标的按钮，比如设置、关闭。32 见方，图标 16，带 tooltip。

- 放在一行的末尾时按笔画对齐：向外伸 8（`iconInset`）再加 4（`glyphRoom`，16 的关闭图标笔画离边 4），× 的笔画落在内容的右边上，和分隔线的端点、菜单行末尾的 ↗ 在一条边上。
- **Don't**：各处自己定按钮和图标的大小。

## 小标题 Section label

一组行上面的小标题，12 号灰字。卡片里用 `cardLabel`（上 16、下 8），菜单栏小窗里用 `panelLabel`（上 12、下 4），侧栏里用 `group`。

- 和下面的行在同一条左边上；上面空得比下面多，靠近它管的那一组。
- **Don't**：缩进，或者在各处自己写边距。

## 星标 Mark

`starMark`：Deneb 的星，按高度给大小。字形左右不留白，左边和旁边、下面的字对齐。

**Don't**：直接用带留白的 `starGlyph` 放在字旁边，看上去会往里缩 2。

## 空状态 Empty state

用在：还没有内容的时候。说一句这里放什么，再给一个下一步，比如"+ 加一台"。

**Don't**：留白，或者写一段话。

## 启动页 Starting page

还没有画面时的整个窗口（DESIGN.md §7.4）：灰色的星，下面一行字说现在在做什么。等久了，下面才多出一行说明和一个动作。

- **Do**：
  - 先说哪里不通，再说还能用什么，最后给一个动作。
  - 星和第一行不动：下面多出来的东西，星的上面留一样多的空。
  - 连上以后一次一件事：星、转圈和字先淡出，主界面再从底色里淡入。
- **Don't**：
  - 一打开就说坏消息：多数时候几秒就连上了，等 10 秒再说。
  - 没联网时说"连不上"（§6.10）。

## 小球 Avatar

用在：一个人，显示首字加主人色。

**Don't**：拿它表示状态。

## 设备块 Device tile

画布上的一台设备，见 DESIGN.md §3.4。只表示设备，不拿来当按钮用。

## 进度 Progress

用在：超过一秒的事，比如下载更新、导出诊断包。能算出比例的显示比例，算不出的只显示在进行中。

- 进度条的长度跟着 Smooth 弹簧平滑地长到新的比例，不一下跳过去。

## 进行中 Busy

点了要等的东西，就在点的地方说正在做（design/plan/m7/loading-and-dividers.md）。

| 种类 | 组件 | 用在 |
| --- | --- | --- |
| 按钮里的进行中 | `busyLabel` | 按钮点了要等：确认、保存、添加、新建局域网、加入、打开、邀请朋友、刷新 |
| 行里的"正在…" | `busyValue` | 一行的值在变：软件更新、导出诊断包的"正在收集" |
| 进度条 | — | 算得出比例的：下载更新 |
| 整页等待 | `waitingWords` | 启动页、登出时：灰色的星，下面一行转圈加字 |

- 转圈只有一个组件（`busyRing`；网页是 `.spin`）。大小和颜色跟旁边的字：按钮里 16，行里 12（网页 `.spin.small`）。
- 时间由 `busy` 管：
  - 自己发起的事用 `begin`、`end`；
  - 只是看得见的事（检查更新、刷新监控数据）用 `follow`；
  - `on` 说这一帧转不转，`working` 说按钮还接不接点击。

- **Do**：
  - 0.2 秒以后才出（`busyDelay`），出了至少留 0.4 秒（`busyHold`）。
  - 结束时一次一件事；结果和原来一样，也淡出淡入一次。
  - 等的时候按钮颜色、宽度都不变，只是不接第二次点击。
- **Don't**：
  - 一点就出转圈：快的会闪一下。
  - 把按钮的字换成"保存中…"：按钮会变宽、变灰，像不能点。
  - 另开一个地方转（窗口角上、另一个弹窗）。
  - 整页盖住等：除了启动页和登出，别处等的时候都能接着用。

## 分隔线 Divider

能用空隙分组的不画线：同一组紧挨着，组与组之间空 16（AGENTS.md §2.4）。卡片灰底块里的行（服务、加入审批、中转站的数），行与行之间空 4。

只在这几处留线：
- 一行里两类东西、地方又小（托盘里的竖线）；
- 滚动时页头下面的边；
- 手机上的列表；
- 控制台的表格。

**Don't**：在卡片、对话框里，一段和一段之间画线。

## 官网（DESIGN.md §14.16）

官网照 Apple 产品页的做法，多了下面几样，只在官网用。

### 顶栏 Site bar

全站一条，高 48，跟着页面走。左边是星和"Deneb"；右边是"使用文档""登录"两个文字链接，最右一个小的主要按钮"下载"。往下滚以后变成毛玻璃；下面是深区时，顶栏跟着用深色那一套。

- **Do**：窄的时候也把链接都露着，放得下。
- **Don't**：
  - 收进汉堡菜单；
  - 在顶栏上放第二个主要按钮。

### 继续链接 Continue link

蓝色文字，后面一个小箭头"›"，比如"了解更多 ›""隐私说明 ›"。用在去别处看更多，和主要按钮并列时它是次要的那个。

- **Don't**：
  - 用它做主要的动作，比如下载；
  - 一处放三个以上。

### 区块 Block

一屏一件事：短标题（展示字号）、一句话（灰）、一张大图或一段小录屏。浅区跟着系统的浅色、深色走；深区标 `data-theme="dark"`，两种模式下都是近黑，放深色的界面。

- **Do**：
  - 浅区和深区交替；
  - 标题和句子只在短语之间断行（每个短语一个 `<span>`）。
- **Don't**：
  - 一块里放两个重点；
  - 写成一段话；
  - 在区块里放表单。

### 大图 Picture

真界面的截图或特写：圆角 16（窄 12），1px 细边，"大"阴影。浅区放浅色界面，深色模式下换成深色；深区只放深色界面。

**Don't**：放示意图、插画、图库照片，或者别家的图。

### 小录屏 Loop

真界面的循环录屏（WebM 和 MP4），盖在同一张图上，开始播放才淡出来。进到眼前才播放，离开就停。右下角一个暂停按钮（36，全圆，半透明）。

- **Do**：
  - 开了"减弱动态效果"、省流量时只放图；
  - 循环的最后半秒淡回开头。
- **Don't**：
  - 带声音；
  - 自动播放的长片；
  - 去掉暂停按钮：循环超过 5 秒就要能停。
