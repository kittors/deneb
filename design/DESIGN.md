# Deneb 组网交互设计

本文档是 demo 和日后客户端共用的设计依据。demo 只验证**交互和 UI**，不实现真实组网。规范一旦和 demo 不一致，以本文为准，再回头改 demo。

---

## 1. 原则

1. **看得见的网络**：设备、连接、中转都画成画布上的东西。用户直接拖、点这些东西，不填表单。**普通人也能顺手用**：用日常说法，不出现 NAT、端口、ACL 这类词，技术细节收在"更多"里。
2. **能拖就不点，能点就不填**：没有表单。每个拖拽操作都有等价的单击操作，触控板用户也能用。
3. **少字**：画面上只留名字和状态（状态胶囊里的总延迟算状态）。技术细节（地址、路径、每段延迟）在悬停或单击时才出现。
4. **状态双编码**：连接状态靠管子的形态（实管、虚线、断开、空管）和电流的有无区分，不只靠颜色，色弱用户也能分辨。
5. **动效有因果**：每个动画都对应一件真实发生的事（握手、打洞、转发、加入），不做纯装饰的循环。
6. **三平台一个样**：外观完全自绘，不依赖任何只在某个平台才有的系统能力（详见 §8）。

## 2. 界面用语

界面只用普通人听得懂的说法。技术词只能出现在"更多"里，或者只出现在本文档里。

| 界面上说 | 意思 | 不要说 |
| --- | --- | --- |
| 局域网 | 一群人把各自的设备放在一起，像在同一个家里 | tailnet、虚拟网络、分组账号 |
| 设备 | 加进来的电脑、NAS、游戏主机等 | 节点 |
| 共享给我 | 别人分给我用的设备 | ACL |
| 直接连上 | 两台设备点对点直接通信 | P2P、打洞、NAT 穿透 |
| 经中转 | 连不上时借一台服务器转一下 | 中继、DERP |
| 中转站 | 帮忙转发的服务器或设备 | relay |
| 服务 | 设备上开给别人用的东西：远程桌面、共享文件夹、网站、命令行 | 端口（端口号只在"更多"里出现） |
| 很快 / 有点慢 | 连接快慢 | 具体毫秒数（收在"更多"里） |
| 只给他用这一台 | 把单台设备分给某个人：对方不进我的局域网，只看得到这一台 | 节点共享、隔离 |
| 拥有者 / 成员 | 局域网里只有两种人：建它的人，和其他人 | Owner、Admin、Member 等 7 种角色 |
| 待同意 | 新设备、新成员要拥有者点一下才能用 | 设备审批、用户审批 |
| 需要重新登录 | 设备的登录快过期了，点一下就续上 | 密钥过期、重新认证 |
| 公共设备 | 不属于某个人、大家一起用的设备（打印机、服务器） | tag 设备 |
| 从这里上网 | 让别的设备上网都从这台出去 | 出口节点、exit node |
| 带上旁边的设备 | 让没装 Deneb 的打印机、摄像头也能被访问 | 子网路由、subnet router |

## 3. 视觉方向（第三版：柔和、亲切、普通人也能用）

> 2026-11-07 第三次改版。第一版扁平、普通；第二版照着实物画，拟物过头，像十几年前的 iOS，还加了底座。用户给了六个参考站：boardui.com、bencho.dev、heroui.com、pro.beui.dev、libraries.dev、ui.watermelon.sh，要求普通人也能顺手用，不要表单式的专业配置。先做一张主界面小样 `design/demos/sample.html` 确认方向，再重做 §9 的场景。

### 3.1 从参考站学到的

- **浅色为主**：白色卡片放在浅灰底上（卡片嵌在"井"里），圆角大，按钮都是胶囊形，留白多（BoardUI、HeroUI、beUI、Bencho）。
- **立体感很轻**：带光泽的彩色小球、圆润的小形状，阴影带一点物体自己的颜色，不画零件和纹理（BoardUI 的颜色球和智能体形象，Libraries 的机器人头像）。
- **光效只用在一处**：沿线或沿边流动的一道渐变光（Libraries 的 border beam、voice ring）。
- **交互动效是主角**：悬停、按下、拖动都有弹性反馈（Bencho）。
- **标题分两段颜色**：一行深色，一行灰色（HeroUI、beUI）。

### 3.2 原则

1. **普通人也能用**：没有表单和专业参数，能拖就拖，能点就点。文案用日常说法，比如"直接连上""经中转""远程桌面"。地址、端口号、延迟数字都收进"更多"。
2. **只有一处亮点**：连线里流动的彩色光，其余都保持安静。
3. **设备按主人上色**：每个人一种颜色，他的设备都用这个颜色，一眼看出是谁的。
4. **浅色为主，深色对等**。

### 3.3 颜色

| 令牌 | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| `bg` | `#FFFFFF` | `#111113` | 窗口、卡片 |
| `well` | `#F4F4F6` | `#19191C` | 画布、侧边栏、卡片里的分组 |
| `line` | `#09090B` @6% | 白 @7% | 1px 描边、分隔线 |
| `ink` | `#18181B` | `#FAFAFA` | 主文字 |
| `ink-2` | `#71717A` | `#A1A1AA` | 次要文字、第二行标题 |
| `ink-3` | `#A1A1AA` | `#6B6B74` | 弱文字 |
| `primary` | `#2F6BFF` | `#4C82FF` | 主要按钮、选中 |
| `ok` | `#22C55E` | `#34D399` | 已连上 |

**主人色**（光泽小球、设备块、连线里的光）：蓝 `#3B82F6`（我）、粉 `#EC4899`、橙 `#F59E0B`、紫 `#8B5CF6`、绿 `#22C55E`、青 `#06B6D4`。同一种颜色在深浅主题里不变，只调整阴影。

### 3.4 设备块

- 60×60 的圆角方块，圆角 18。底色是主人色的纵向渐变：上浅（混 18% 白），下深（混 8% 黑）。
- 顶部内侧有一道柔和的白色高光，左上角有一块小光斑，像 BoardUI 的颜色球。阴影带主人色：`0 8 18 主人色 @30%`，加一层 `0 1 2 黑 @10%`。
- 中间是白色实心设备图形，28px。
- 名字在方块下方 10px，字号 13 / 500；第二行是状态，字号 12，颜色 `ink-2`。
- 离线时变成灰色方块，图形半透明。
- 悬停时上浮 2、阴影变大；按下时缩到 0.96；拖动时放大 1.06、略微倾斜。

### 3.5 连线

- 一条 3px 的透明轨道：浅色主题用 `#09090B` @7%，深色主题用白 @8%。
- 轨道里流动一道彩色光：2px 亮芯加 6px 柔光，颜色从一端主人色渐变到另一端主人色，长约 80px，速度 140 px/s。流量大时光更密。
- 经中转时，轨道从中转站穿过，光到中转站会停一下再继续。
- 正在连接时，轨道从两端画出来，在中间接上，光再流进去。
- 连不上时只剩一条灰色虚线。

### 3.6 中转站

一个 40px 的白色光泽小球（深色主题是浅灰），中间是中转图形。名字只写地点，比如"香港"；来源（我的服务器、朋友的设备、公共）写在第二行。

### 3.7 人

- 每个人是一个 32–40px 的光泽小球，用主人色，中间是名字的第一个字。
- 画布底部浮着一条"人"的胶囊栏：把设备拖到某个人身上就是分享给他，点 "+" 邀请新朋友。
- 不让某人用时，他的小球变灰，并加一道斜线。

### 3.8 界面

- 窗口圆角 16。侧边栏是浅灰的 `well`；画布也是 `well`，内容卡片用白色 `bg`。
- 按钮都是胶囊形：主要按钮为 `primary` 实心，次要按钮为白底加 1px `line` 描边。
- 点设备会弹出白色卡片（圆角 20），上面是谁能用（光泽小球）和开放的服务（远程桌面、共享文件夹、网站……每个配一个开关）。端口号和地址收在"更多"里。
- 开关：胶囊轨道，开着时是 `primary`，白色圆钮，弹簧动画。

### 3.9 字体、圆角、间距、阴影

- 字体：客户端用 `ui.RegisterFont` 内嵌一款开源黑体（候选 HarmonyOS Sans SC、Noto Sans SC 子集），三平台一致；demo 用系统字体 `-apple-system, "SF Pro Text", "PingFang SC", "Microsoft YaHei UI", sans-serif`；数字等宽（`tnum`）。字号 12 / 13 / 15 / 20 / 28，字重 400 / 500 / 600。
- 圆角：窗口 16，弹出卡片 20，卡片里的分组 14，设备块 18，按钮和小球为全圆。嵌套时遵守同心规则。
- 间距以 4 为基数，常用 8 / 12 / 16 / 24 / 32。
- 阴影都是两层，柔和、带一点颜色：小 `0 1 2 @6% + 0 1 1 @4%`，中 `0 8 24 @8% + 0 2 6 @5%`。

## 4. 避让

- 管子、光点、浮层都不能压住名字。必要时改变弯曲方向，或者挪开中继。
- 浮层从底部弹出时，整张图用 Smooth 弹簧上移给它让位，关闭后落回原位。
- 中心设备（所有管子都从它出发）的名字放在线最少的一侧：场景 3 的线往左右和下方走，名字在上方；小样和场景 5 的线往四个斜角走，名字在下方。
- 别人的第二行会变长时（"用不了这台电脑"），连到他的线往外弯，不贴着名字走。
- 拖着设备时，它的连线像软绳一样跟着走，其余的线保持不动；松手停稳后才统一绕开（§6.3）。拖到托盘上方时（场景 5），它的连线变淡，预告松手就断开。
- 光标单击之后要离开文字（只影响录屏剧本）。

## 5. 动效规范

| 名称 | 参数 | 用于 |
| --- | --- | --- |
| Smooth | 弹簧 500ms，bounce 0 | 布局、面板开合、聚焦切换、线的跟随 |
| Snappy | 弹簧 400ms，bounce 0.15 | 节点出现与落位、悬停抬起、按压回弹 |
| Bouncy | 弹簧 550ms，bounce 0.32 | 只用于"接通"：中继落下、成员加入 |
| Fade | 160ms EaseOut | 颜色、透明度 |
| Draw | 420ms EaseInOut | 连线生长与收回 |
| Stagger | 每项 60–70ms | 多个节点或多条线依次出现 |
| Pulse | 1.6s 循环，往返 EaseInOut | 占位圈呼吸、建立中的提示 |

- 弹簧在目标改变时保留当前速度（MyGo 的 `AnimateTo` 本身就是这样），连续点击不会卡顿。
- 交互反馈在 100ms 内开始；单个过渡不超过 600ms（循环动画除外）。
- 减弱动态效果时：位移直接到位，颜色和透明度照常淡变，光点照常流动（表示"连着"，作用和系统转圈一样）。

## 6. 交互规范

### 6.1 拖拽的四个状态

1. **静止**：光标为抓手；悬停时目标微微抬起。
2. **按下**：缩到 0.96–0.97（60ms）。按下立刻有反应。
3. **拖动**：移动超过 4px 后进入拖动。设备块、名字、状态整块跟着指针走，连线跟着走；拖着时名字下面垫一层窗口底色，压在别的节点上也看得清；设备块放大 1.06、略微倾斜（−3°），阴影略深一点但保持柔和，是中性的灰影，不扩散成带颜色的一大片光晕。画布上挪动的节点（设备块、中转站、局域网区域）原位不留任何影子；松在不允许的地方，就用 Smooth 弹回原位，不需要影子来提示原位。只有从容器里拿出来的东西（托盘里的中转站或设备），容器里那一格变淡，表示东西从这里拿走了；场景 4 的列表里拿起的格子或行留一个空位，列表用弹簧给它让地方。拖着的东西浮在所有东西上面（卡片、托盘、提示条都在它下面）。能接收它的目标在指针靠近时亮起蓝色描边。拖着的东西如果会盖住目标（成员行、侧边栏的一行、托盘），就以指针为中心缩小，让目标露出来。
4. **释放**：落在目标上，Snappy（接通时用 Bouncy）落位，目标播放确认动画；落在空处，就停在那里（见 6.3 的避让）；落在不允许的地方，用 Smooth 弹回原位。松手时还在动，节点带着手的速度落到位置上，不会急停；已经在弹的节点再被指去别处，保持原来的速度转向，不会停一下再走。落位、弹回都等弹簧真正停稳才算结束，最后不会再跳一下。按 Esc 等同弹回原位。

### 6.2 每个节点都能拖

画布上的每个节点都能拖：设备块（包括"这台电脑"）、中转站、场景 3 的局域网区域，以及场景 4 后台里的设备块和成员。

- **软绳**：连线像软绳一样跟着节点走。线的两端紧跟节点，中间稍慢半拍跟上，停下时不来回晃。线上的状态胶囊贴着线一起走。
- **停在松手处，下次还在**：松手后节点就停在那里，摆放存在本机，下次打开还是这个位置。demo 控制条的"重播"会把摆放还原成默认。
- **摆放和归属分开**：别人的设备在我的画面上也能挪位置，这只是我自己的摆放。但"移出局域网"这类改归属的操作只有主人能做：别人的设备和"这台电脑"拖不进托盘，到托盘上方就停住，托盘用一句话说明原因（"这是阿杰的设备，只有阿杰能移出"、"正在用的这台电脑不能移出"）。不摇晃，不弹提示条：东西根本放不进去，就没有"失败"这回事。场景 3 里拖不出自己的区域，也是到边上停住、区域边上说明原因。
- **场景 4 的后台**是列表，不是自由画布：设备块拖到另一个格子上就是换位置，成员行上下拖就是排序，其余格子和行用弹簧让出位置；成员拖到设备上和设备拖到成员上一样，都是分享。

### 6.3 避让

- **松手后才避让**：拖着节点时，除了手里的节点和它自己的连线，画面上什么都不动：别的节点不让，别的线不换弯，胶囊不挪；经过别的节点时的重叠只是暂时的。松手后，放下的节点吸到最近的空位（离别的设备块和名字至少 22px，尽量不压在别的线上，同样近时回到它来的那一侧）。设备块、中转站、名字在静止时任何时候都不能重叠。
- **不出画面**：拖着的节点限制在画布可见范围里，不能拖出窗口；松手后连名字也完整留在画面里。
- **线绕开节点**：连线不从别的设备块、中转站和名字底下穿过；挡住了就换弯曲方向（往另一边弯，或弯得更多）。只在所有东西停稳以后才换，每次只换一回，用软绳的弹簧过渡，不会突然翻面，也不会来回换。
- **胶囊找空地**：线上的胶囊贴在线上，跟着线走，不滞后、不飘离。停稳以后，如果它压到名字、设备或别的线，就沿着这条线滑到最近的空地。
- **浮层不挡正在操作的节点**：画布从不为卡片挪动。拖着东西（或东西还在飞）时，卡片淡出让开，停稳后再淡入；松在卡片的位置上，会吸到它旁边的空位。卡片在自己的一层里，进出场都盖在设备上面，不会和设备交叠穿插；提示条会盖住刚放下的节点时，改到画布顶部出现；托盘、卡片、邀请卡所在的地方不能放节点，松在那里会吸到旁边的空位。

### 6.4 拖拽组合规则

所有场景都按这张表来。拖什么、放到哪里，结果只有一种，用户不用记菜单。

| 拖什么 | 放到哪里 | 结果 | 能撤销吗 | 不想拖的话 |
| --- | --- | --- | --- | --- |
| 任何节点 | 画布上的空处 | 停在那里，只是换个摆放 | 拖回去就行 | — |
| 我的设备 | 某个局域网的区域，或侧边栏里那个局域网的一行 | 加进这个局域网。从另一块区域拖过来，就是挪过去 | 能 | 单击设备，在卡片里点局域网的名字 |
| 局域网里我的设备 | 托盘，或区域外的空白处 | 撤出这个局域网 | 能，提示条"已移出 · 撤销" | 卡片里的"移出这个局域网" |
| 设备 | 某个人的小球（标题区的小球叠、成员行） | 分享给他（§6.11） | 能，"已收回 · 撤销" | 卡片"分享给"里点 "+" |
| 我的中转站 | 画布上，或两台连不上的设备之间 | 这个局域网用它，连不上的那条经它接上（§6.12） | 能，拖回托盘也行 | 单击托盘里的中转站，它自己飞到推荐位置 |
| 我的中转站 | 托盘 | 这个局域网不用它了（公共的、朋友的拿不走） | 能 | 卡片里的"不用这个中转站" |
| 人的小球 | 某个局域网（区域或侧边栏那一行） | 邀请他加入 | 对方接受前都能收回 | 标题区的"邀请朋友" |
| 别人的设备、这台电脑 | 托盘、区域外、另一块区域 | 不行：拖到边上就停住，托盘（或区域）说明原因，例如"这是阿杰的设备，只有阿杰能移出"；松手后停在附近的空位 | — | — |

- 一台设备要同时留在两个局域网：从侧边栏"我的设备"里再拖一次进去。拖着区域里的设备走，永远是"挪"，不会悄悄多出一份。
- 画面上有几块区域时（场景 3），松在区域外的空白处就是撤出；在自己的区域里松手只是换位置。画面只有一个局域网时（场景 5），整个画布就是这个局域网，松在画布上只是换位置。

### 6.5 其他

- **托盘的话跟着手上的东西变**：平时写"拖出来，加进局域网"（里面的设备往上拖就加入，单击它会自己找个空位）。拖着我的设备靠近时写"拖到这里，移出局域网"，描边淡蓝；到托盘上面（以托盘本身为准，托盘两旁的底边不算）时描边变成蓝色、文字变成"松手，移出局域网"，末尾让出一个空格，设备块缩成托盘里的大小、名字淡出、连线变淡。松手后设备块飞进那个空格，轨道收回。拖着别人的设备靠近时，托盘只说明原因（§6.2）。托盘里没有设备时收起，拖着我的设备靠近时再升起；托盘、空格、文字的伸缩用同一个弹簧，一起动。
- 移除类操作立即生效，底部出现提示条"已移出 · 撤销"，4 秒后消失，指针停在上面时不消失。不弹确认框。提示条和托盘、卡片一样是浅色胶囊：白底、1px 细边、柔和阴影，左边是那台设备的小图标，右边是蓝色文字按钮"撤销"。它从下方升起、淡入，消失时下沉、淡出；新的提示接替旧的时，胶囊不动，文字淡入替换。会盖住刚放下的设备时改到画布顶部（§6.3）。
- 设备卡片从右上角缩放淡入（0.96 → 1，约 200ms），关闭时缩回淡出；换一台设备时内容淡入替换，高度平滑过渡；点画布空白处或 × 关闭。拖拽时卡片让开（§6.3）。"谁能用"按设备分别记：在游戏主机上不让 Mia 用，不影响这台电脑。小球变灰、斜线从中间画出来，名字一起变灰。
- 每个拖拽都有单击替代：单击托盘里的中转站，它会飞到推荐位置。
- 单击设备弹出设备卡片，用一句话说明它现在怎么连的；地址、端口号收在卡片的"更多"里。

### 6.6 不许出现的问题

没人拿着的东西（节点、名字、胶囊、区域、列表里的格子和行）：
- 不能瞬移，不能单帧跳一下又回来，不能从运动中急停，也不能从静止直接全速出发；
- 不能在 0.6 秒内来回晃 4 次以上；
- 透明度不能闪一下又回来；大小不能一帧变化超过 8%；
- 连线不能在 1.5 秒内换两次弯；卡片刷新内容时不重播入场动画，打开的"更多"保持打开；新的提示条和旧的交叉淡入，不闪。
- 拖起时，按住的那个点一直在手下，设备块不会跳到指针中间。

每次录屏都会生成逐帧记录，用 `design/tools/motion-check.mjs` 检查以上各条，结果为零才交付（§11）。

### 6.7 局域网卡片、邀请和"待同意"（M2）

> M2 的设计稿，先在客户端的演示模式里做出来，用户看过再定稿。

- **局域网卡片**：单击标题区的局域网名字，右上角弹出局域网卡片，和设备卡片同一层、同一套进出动画（换成设备卡片时内容淡入替换）。上面是名字、"拥有者 kittors"、成员的小球。拥有者另有两个开关："新设备要我同意""新成员要我同意"；成员看到的是同一张卡片，没有开关。新建的局域网两个都默认开（用户已定，2026-11-08）；M1 时建的局域网迁移后是"设备关、成员开"。
- **把人拖到局域网上就是邀请**（§6.4）：标题区小球叠里的人、"全部"视图区域标题上的成员小圆点，都能拖。拖起来时跟着手的是一枚小胶囊（小球加名字）；经过侧边栏里某个局域网那一行，或者"全部"视图里某块区域时，它亮起蓝色描边。松手就发出邀请：那个局域网的小球叠里多一个虚线小球（"等他接受"），提示"已邀请 Leo 加入桌游夜 · 撤销"。对方接受前，悬停虚线小球会露出一个小"×"，点它就收回。已经在里面的人：那一行左右摇一下，写"已经在了"。
- **收到的邀请**：别人直接邀请我（不是发链接）时，窗口右上角弹出和链接一样的卡片"Leo 邀请你加入「桌游夜」"。点"以后再说"只是先收起：侧边栏"局域网"下面多一行灰字"Leo 邀请你 · 桌游夜"，单击这一行重新打开卡片。邀请一直留着，直到我加入、拒绝，或者它过期。
- **谁要等**：拥有者自己的设备从来不用等。拥有者亲手邀请的人（发链接或拖人）接受后直接进来，他用来接受邀请的那台电脑也跟着一起进；他之后再往这个局域网里加的设备，开着"新设备要我同意"时要等。成员发出的邀请，对方接受后，开着"新成员要我同意"时要等拥有者。
- **待同意的设备**：拥有者打开"新设备要我同意"后，别人拖进来的设备先以虚线块出现在拥有者的画布上：和设备块一样大，没有填充，1.5px 主人色虚线描边，图形用半透明的主人色。名字照常，第二行写"等你同意"，它和"这台电脑"之间不画线。
  - **同意**：单击虚线块，它用 Bouncy 填满成实心设备块，轨道从"这台电脑"长出来，提示"已同意阿杰的 NAS 加进来 · 撤销"。撤销后变回虚线块。
  - **不同意**：悬停时虚线块右上角露出一个小"×"，点它，虚线块缩小淡出，提示"已拒绝阿杰的 NAS · 撤销"。
  - **设备主人自己的画面**：那台设备同样是虚线块，第二行写"等阿杰同意"；悬停露出的"×"是撤回，不加了。拖进来那一下就是虚线块，提示条写"构建服务器等阿杰同意 · 撤销"（撤销就是撤回），不写"已加进"。阿杰拒绝时提示"阿杰没有同意构建服务器加入「周末联机」"，虚线块保持虚线飞回托盘，不能一声不响地消失。（M2 真机验收第 13 条，2026-11-08 主会话定）
  - **侧边栏提醒**：有东西等拥有者同意的局域网，那一行末尾有一个小蓝点，处理完就消失。
- **待同意的人**：打开"新成员要我同意"后，拿成员发的邀请进来的人，先以虚线小球出现在拥有者标题区的小球叠里。单击虚线小球就是同意，悬停露出的"×"是拒绝，提示和撤销同上。他带来的设备，同意之后才出现。
  - **等着的人自己这边**：侧边栏里那一行是灰字，后面写"等同意"。点进去，画布中间只有拥有者的小球和一句"等阿杰同意你加入「周末联机」"。
- **"已连接"计时**：这台电脑正在用某台设备的服务时（比如连着 dev-db 的数据库），那台设备的第二行写"已连接 2:14:08"，从开始用算起，每秒走一次，数字等宽，走的时候不抖；不用了，就回到"直接连上"。

### 6.8 登录快到期、连不上的原因、同名设备、和 Clash 共存（M2）

- **需要重新登录**：只出现在我自己的设备上。
  - **快到期**：离到期还有两周起，设备块右上角出现一个琥珀色小点，第二行写"需要重新登录"。单击小点就续上，不用打开卡片：小点缩掉，提示"已续上"。卡片的状态块写"需要重新登录 / 还有 12 天到期"，右边一个小按钮"续上"。
  - **已经到期**：设备块变灰，和不在线一样，小点还在，第二行写"登录过期了"。单击小点同样续上。
  - **这台电脑**到期时，窗口回到只有"登录"按钮的样子（和第一次打开一样），登录后一切照旧。
- **连不上的原因**：设备块第二行只写短的状态；卡片的状态块写一句原因，右边配一个能点的动作。

| 情况 | 第二行 | 卡片里的原因 | 动作 |
| --- | --- | --- | --- |
| 对方不在线 | 不在线 | 上次在线：3 小时前 | 上线时告诉我 |
| 别人的设备登录过期 | 登录过期了 | 要等阿杰在那台设备上续上 | 提醒阿杰 |
| 我的设备登录过期 | 登录过期了 | 续上就能连 | 续上 |
| 主人不让我用 | 主人不让你用 | 要用的话，问问阿杰 | 问问阿杰 |
| 路由器不让直连，也没有中转站 | 连不上 | 两边的路由器都不让直连 | 加一个中转站 |

  - **上线时告诉我**：点一下就开，按钮变成"上线时会告诉你"，再点就关。对方上线时，窗口底部出现提示"阿杰的 NAS 上线了"；窗口不在前台时，用系统通知。
  - **提醒阿杰、问问阿杰**：复制一句现成的话（"你的阿杰的 NAS 在 Deneb 里登录过期了，打开 Deneb 点一下续上就好"），提示"已复制，发给阿杰就行"，和"邀请朋友"一样。
  - **加一个中转站**：中转站托盘升起，推荐的那个自己飞到两台设备之间（和场景 2 单击托盘里的中转站一样）。
- **同名设备**：同一张画布上有两台名字一样的设备时，后加进来的那台，名字后面跟一个灰色的小号"2"（第三台跟"3"）。这只是画面上的区分，不改名字。
  - 点开它的卡片，名字下面多一行"和另一台同名 · 改个名字"，点"改个名字"就是就地改名（§6.9）。
  - 我自己的同名设备里，如果有一台 30 天以上没上线，它的第二行写"旧的那台 · 很久没上线"，卡片里有"不用了？移出这个局域网"。
- **和 Clash 一类软件共存**：用户态下 Deneb 绑着物理网卡，自己就绕开了 Clash、Surge、v2rayN 的增强模式（TUN），什么都不用提示。只有引擎发现别的软件真的接走了 Deneb 的连接（比如内核网卡模式下，去往局域网地址的流量被它们转走了），标题区右边（小球叠左边）才出现一枚琥珀色小胶囊："Clash 可能挡住连接"。它不放在画布上，免得盖住设备。
  - 点它，右上角弹出卡片（和设备卡片同一层）：一句完整的话（"Clash 正在接管网络，局域网里的设备可能连不上"）、一条要在那个软件里加的规则，下面"知道了"和"复制规则"。Deneb 只给出规则，不替用户改别的软件。
  - 点"知道了"，胶囊和卡片一起收起，同样的情况下次不再提示。

### 6.9 改名、改种类（M2）

- 只能改我自己的设备；局域网只有拥有者能改名。
- **改名**：单击设备卡片里的名字，名字就地变成输入框，原名全选；回车或点别处就改好，画布上的名字跟着变；按 Esc 取消。名字可以有中文和空格，太长时画面上照常截断（结尾"…"）。局域网改名在局域网卡片里，做法一样。
- **改种类**：单击卡片左上角的设备图形，下面展开一排种类图形：笔记本、台式机、服务器、NAS、手机、游戏主机、其他。当前那个带蓝色描边，点一个就换：画布上设备块里的图形淡入替换，这一排收起。再点一次设备图形，也会收起。

### 6.10 这台电脑没联网（M2）

这台电脑自己断了网（Wi-Fi 关了、网线拔了、在飞机上），对面的设备都好好的。这时每台设备都写"连不上"会吓到人，也会让人去查错地方：问题在这台电脑，不在对面。所以引擎报"这台电脑没联网"时，画面这样说（2026-11-08 真机断网 15 秒时发现，主会话定的方向）：

- **标题区**：标题下面那句换成"这台电脑没联网，联网后会自动连上"，前面的小圆点是灰色。"全部"视图也一样。
- **设备**：别人的设备和我其他的设备都变灰（和"不在线"一样的灰，300 毫秒渐变），第二行写"等这台电脑联网"；连线不再流光，变成静止的点线（和"不在线"一样）。点开卡片，连接那一行写"等这台电脑联网 · 这台电脑没联网，联网后会自动连上"，不带按钮（不像"不在线"有"上线时告诉我"）。"这台电脑"自己照旧写"你正在用"。整个画面不出现"连不上"，也不出现连不上的原因句。
- **菜单栏**：图标是闭眼的小星（这台电脑现在什么也连不了，和"都暂停了""Deneb 没在运行"一样）。面板头部写"这台电脑没联网"，前面灰点；局域网那几行写"等这台电脑联网"；"要你处理"里不放"连不上"那一类。开关照常能拨。
- **网回来以后**：照现在这样，各台先"正在连接…"（流动的点线），连上后轨道从两头长出来，写"直接连上"或"经香港中转"；标题那句回到原来的样子。中间不出现"连不上"。
- 是不是"没联网"由引擎判断、报一个问题代码（引擎线加），界面只照它说。演示里按 ⌥⌘L 切换：没联网 → 网回来（先正在连接，2 秒后连上）。

### 6.11 只给他用这一台、共享给我、位置（M3）

> **用户 11-10 看过，按推荐定**（M3 桌面端第 1 批，交付在 `M3-设备共享和Web/第1批-桌面端分享/`，总览页 `设计待审总览.html` 第 1 批）：唯一要选的一条，"共享给我"里的"不要了"，按推荐**留着**。客户端照这一节接了真实数据（分享、共享给我、位置额度）。依据：实现计划 §3 M3，定价文档 §1.4、§1.5，控制线 `design/plan/m3/control.md`。控件照服务器的功能列表出现：没有 `share` 就没有分享，没有 `seats` 就不出现任何位置的字样，没有 `shareMode` 就没有"只用分到的设备"和"不要了"；这时画面和 M2 一样。

**分享：把我的设备拖到一个人的小球上**（§6.4）

- **能拖的**：我的设备，画布上的、托盘里的都行，"这台电脑"也行。别人的设备拖起来时，下面这些都不出现。分给谁才有用：局域网里的成员本来就看得到这个局域网里的设备，所以在一个局域网的画布上，通常是把托盘里的设备（不在这个局域网里的）拖给某个成员；"共享给我"里是把"这台电脑"拖给分享给我的人；设备共享模式的局域网里，画布上的设备拖给成员就是分给他。
- **小球叠散开**：拿起我的设备，标题区右边的小球叠向左散开（Snappy），小球之间空出 8px，每个人都完整露出来；我自己的小球和虚线小球（待同意、等接受）淡到 40%，它们不接收。小球叠下面出一行 12px 灰字"放到谁身上，就只给谁用这一台"。松手后小球叠收回，这行字淡出。
- **拖进标题区**：拿着我的设备时，设备块可以往上离开画布、进到标题区（只在这时，别的时候照旧不出画布）。进了标题区，设备块缩到六成、名字淡出，它的连线几乎淡没（拿的是"这台电脑"时，所有连线都淡下去），免得一根线从画布中间拉到标题区。
- **指到谁**：设备块再缩小，吸进那个小球里（不管手捏着设备块的哪儿），小球亮起蓝色描边、放大到 1.15，下面那行字变成"松手，只给 Mia 用这一台"。离开小球，设备块回到手下。放不了的人，设备块也吸进去，但小球不亮（见下）。
- **松手**：设备块带着手的速度飞回原来的位置（分享不改摆放，托盘里的回托盘那一格），那个小球弹一下（Bouncy）。提示条"已把我的 NAS 分享给 Mia · 撤销"；撤销就是马上收回，位置也马上放出来（不再有"已收回"那一条）。
- **放不了的，拖着时就知道，不摇晃、不弹框**：小球不亮，那行字说为什么，松手设备块回原位。已经分给他了："Mia 已经有了"；他和这台设备在同一个局域网里、本来就能用："Mia 已经能用了"；位置满了、他又不在我的名单上："位置满了"（定价文档 §1.5 第 3 条，见下面"位置"）。
- **开放哪几项**：分享出去时，开放的就是这台设备现在开放给局域网的那几项（卡片"开放给大家的"里开着的）；它不在任何局域网里，就是它以前开过的那几项。一项都没有时先不开放，在卡片里打开。
- **单击替代**：卡片"分享给"里的"+"（见下）。

**我的设备的卡片：分享给**

- "谁能用"下面多一段"分享给"：一排胶囊，每个分到的人一枚（小球加名字），最后一枚是虚线圈里的"+"。还没分给任何人时只有一枚"+ 分享给别人"。
- 胶囊下面一行 12px 灰字，说清方向：分给一个人时"只有 Mia 能连你，反过来不行"，分给几个人时"只有他们能连你，反过来不行"。（§12 第 12 条）
- **换开放的几项**：单击 Mia 的胶囊，下面展开"开放给 Mia 的"，每项一个开关，和"开放给大家的"一样；再点一次收起。关掉 Mia 正在用的那一项时，和场景 5 一样是"X被关了"那套。
- **收回**：悬停胶囊，右上角露出小"×"（和虚线小球的"×"一样）。点它马上收回：胶囊缩掉，提示"已从 Mia 收回我的 NAS · 撤销"；撤销就原样回来，开放的那几项也回来。提示条走了（到时间、被新提示条顶掉、切画布、窗口藏到菜单栏）才告诉服务器"撤销窗口关了"，这时位置才放出来；在那之前撤销一定成功（控制线的约定，`share.release`）。

### 6.12 中转站（M4）

> **用户 11-10 看过，按推荐定**（M4 第 1 批，交付在 `M4-中转站/第1批-桌面端中转站/`，总览页 `设计待审总览.html` 第 4 批）：托盘里**不放**公共中转站；"连不上"**只在真的连不上时**写（连公共中转站也连不到）；只有地址的中转站，句子里叫"**我的服务器**""**阿杰的服务器**"，地址只留在小球和卡片标题上（文末三条）。客户端照这一节接了真实数据。用户 11-09 定了家里的设备当中转站挪到公测以后，所以朋友的中转站换成了朋友的服务器（"东京 · 阿杰的服务器"），M4-03 照这个重录。依据：实现计划 §5 最后一行；定价文档 §2.4（说法以它为准）；控制线 `design/plan/m4/control.md` §1、§13、§16；网页 §14.8 和 M3-15（网页、桌面端一个样子）。服务器没有 `relays` 功能时，下面这些都不出现，画面和 M3 一样。

**三种中转站，各在哪儿**

- **公共中转站**（"香港 · 公共"）：我们出的，一直兜底：直接连不上，或者局域网自己的中转站用不了时，自动经它中转。它不用拖、也拿不掉，所以不进托盘（见文末"要你定"第 1 条）。画布上，只有连线经过它时才出现，和场景 1 一样弹出来，用完缩小淡出。
- **我的服务器**（"198.51.100.4 · 我的服务器"）：我拖进哪个局域网，那个局域网就用它，排在公共的前面。在这个局域网里的就在画布上，没有连线经过时也在，只是没有线；不在的在托盘里。
- **朋友的中转站**（"东京 · 阿杰的服务器"）：阿杰拖进这个局域网的，和我的一样在画布上。我拿不走，也管不了。家里的设备当中转站挪到公测以后（用户 11-09 定）。
- 小球照 §3.6 画：第一行写地点，问不到地点时写地址；第二行写来源（"公共""我的服务器""阿杰的服务器"）。连不上时小球变灰（和不在线的设备一样淡），第二行写"连不上"。
- **句子里怎么叫它**（见文末"要你定"第 3 条）：有名字（地点，或主人起的名字）就叫名字："经香港中转""经公司机房中转"。只有地址的，小球和卡片标题照样写地址，方便认出是哪一台；但句子里不写地址，写它是谁的："经我的服务器中转""周末联机用上了我的服务器""已不让阿杰用我的服务器"，别人的写"经阿杰的服务器中转"。拉丁字母、数字和汉字之间空一格（"Mia 的设备"），日期照常写（"11月6日"）。
- 中转站在画布上都能拖着换位置，避让规则和设备一样（§6.3）。几个中转站同时在画布上时，彼此也让开。经过中转站的连线不压名字，也不穿过设备块（场景 1 末尾）。

**托盘里的中转站**（§6.4、§6.5）

- 托盘里先放我的设备，后面隔一道竖的细线，放我的、不在这个局域网里的中转站，最后一格是虚线圈里的"+"，用来"用我自己的服务器"。托盘的说明照旧写"拖出来，加进局域网"，指着"+"时换成"用我自己的服务器当中转站"。
- 有这个"+"，托盘就一直在。没有设备、也没有中转站时，托盘里只有"+"和那句说明。
- **拖进来**：从托盘拖出来（出了托盘就长成画布上的大小，路过的设备让开），放到画布上任何空处，这个局域网就用它了（`relay.add`），提示"周末联机用上了公司机房 · 撤销"，撤销就飞回托盘。原来经公共中转站的连线随即改走它（自己的中转站排在前面）：轨道从公共中转站挪到它身上，光不断；公共中转站没有连线了，就缩小淡出。放在一条"连不上"的线上，就是场景 2：那条线经它接上。单击托盘里的它，它自己飞到推荐位置：有连不上的线，就飞到那条线中间的下方；没有，就飞到经公共中转站的那几条线旁边；也没有，就在"这台电脑"下方找个空位。
- **拖回托盘**：这个局域网不用它了（`relay.remove`），和卡片里点"不用这个中转站"一样。提示"周末联机不用公司机房了 · 撤销"。经它的连线先改走公共中转站，光不断；等经过它的那段线淡掉，它再缩小着飞进托盘里给它空出来的那一格（线不会在空处拐弯）。撤销就从那一格飞回原来的位置。
- 公共的、朋友的中转站，拖到托盘上方就停住，托盘说明原因（和 §6.2 拖别人的设备一样）："公共中转站一直都在，拿不掉"，"这是阿杰的中转站，只有阿杰能拿走"。松手后停在附近的空位（同 §6.4 最后一行）。

**公共中转站的卡片**（M4-01：单击它；经它连的设备，卡片里"经香港中转 · 公共中转站，慢一点但能正常用"那一行也能点开，经我的、朋友的中转站也一样）

- 头部：中转站小球，"香港"，第二行"公共中转站"。
- 状态那一行和设备卡片里"直接连上 · 很快"是同一种：绿点"在线"，后面写"离你很快"（来回 80 毫秒以内）或"离你有点慢"。
- 两句话："自动兜底，不用管。直接连不上，或者局域网自己的中转站用不了时，自动经它中转。""内容全程加密，中转站看不到。"
- "更多"里：现在经哪个中转站（"香港 · 103.42.31.155"）、延迟（"52 毫秒"）、"每条连接限速 2 MB/s"。限速写明，不悄悄限。
- 不写别人用了多少，没有任何按钮。

**我的服务器的卡片**（M4-02）

- 头部：小球、名字，第二行"我的服务器"。名字就在原地改（同 §6.9）：单击名字变成输入框，回车改好，画布上的名字淡入替换。服务器问不到地点时，名字是它的地址（真机上就是 198.51.100.4），改个好记的名字就行，比如"公司机房"。
- 状态那一行：绿点"在线"，小字"已经运行 12 天"（刚装好的写"刚上线"）。连不上时是灰点"连不上"，小字"刚停，经它的连线先走公共中转站"，过一会儿是"3 分钟没报到，经它的连线先走公共中转站"。
- "现在"：两行，"在用 · 3 个人 · 5 台设备"（没人时"还没有"），"忙不忙 · 不忙"（"有点忙"，满了写"满了，新连上来的先走别的"）；连不上时两行都是"—"，下面的"谁在用"也不出现。
- "这个月替你转了"：每个局域网一行，前面是局域网的色点和名字，右边是流量，例如"周末联机 12.4 GB"；分享出去的设备合在"分享"一行里，有才出现。

- "不让用的"：最近 30 天里不让用过的人，灰色加斜线的胶囊，胶囊后面写哪天（"今天""11月6日"）；点一下就又让他用，提示条能撤销。一个都没有时，这一段不出现。
- 一句话："内容全程加密，你也看不到；你能看到谁在用、用了多少。"
- "更多"里：地址、延迟、"不限速"。
- 最下面是灰色的"不用这个中转站"，位置和样子同"移出这个局域网"：小球飞回托盘，和拖回托盘一样，能撤销。

**朋友的中转站的卡片**（M4-03）

- 头部："东京"，第二行"阿杰的服务器"。
- 状态那一行："在线 · 离你很快"（慢的写"离你有点慢"；眼下没有设备经它连、不知道快慢时写"随时能用"）。
- 一句话："内容全程加密，阿杰看不到；阿杰能看到谁在经它连、用了多少。"
- "更多"里：延迟、限速。
- 没有开关，没有按钮，名字也不能改。

**改走公共中转站**（M4-04）

- 正经我的服务器中转的时候，它停了（关机、断网、被拔了线）：经它的连线马上换到公共中转站。公共中转站在旁边的空位弹出来，轨道从我的服务器挪过去，光不断，不出现"断开"。这些设备的第二行写"改走公共中转站"，卡片里写"改走公共中转站 · 公司机房连不上，先经香港中转"。
- 我的服务器的小球变灰，第二行写"连不上"。不出提示条：和场景 1"网络变了"一样，画面上看得到就够了。
- 它回来以后自动换回：轨道挪回它身上，公共中转站缩小淡出，小球恢复原样，设备第二行回到"经公司机房中转"。

**用我自己的服务器**（M4-05，和网页 M3-15 一个样子）

- 单击托盘里的"+"，右上角弹出卡片：头部是虚线圈的中转站图形、"用我自己的服务器"，第二行"装好后，它自己出现在托盘里"。下面写"在服务器上运行这一行"，接着是一块浅灰底的等宽字，命令由服务器拼好，只在空格处换行（不会把"--restart"拆成两行）；右下角是"复制"，点了变成"✓ 已复制"，整段一字不差。命令很长，不让手去选，免得少选一截。再下面一行灰字"1 小时内有效，只能用一次，要先装好 Docker"。最下面一行"不装也能用：直接连不上时，自动经公共中转站"。

**用户 11-10 定了（都按推荐）**

1. **托盘里放不放公共中转站。** 推荐不放：
   - 托盘的意思是"拖出来，加进局域网"，里面每样东西都能拖，拖了就有变化。公共中转站一直在用，拖不动也拿不掉，放进去就是托盘里唯一一个拖了没用的东西（§6.2）。
   - 普通人不用记着它。它在需要的时候自己出现在画布上：有连线经过时才出现，点它就是上面那张卡片，这时说"离你多远""限速多少"才有意义。
   - 想知道它在不在的人，有两个地方能看到："用我自己的服务器"那张卡片最下面那句；网页后台的"中转站"一页一直列着它（§14.8）。
   - 如果你想让它一直看得见：就放在托盘最后，画得淡一点、不能拖，拖它时托盘说"公共中转站一直都在，不用拖"。代价是托盘里多了一样拖不动的东西。
2. **有公共兜底以后，场景 2 的"连不上"什么时候还会出现。** 推荐只在真的连不上时出现：直接连不上，而且至少有一边连不到任何中转站，公共的也连不到。实际会碰到的有两种：那边的网络拦着公共中转站（只放网页的公司、学校网络，或者跨境线路断了）；公共中转站自己出了故障，而这个局域网又没有自己的中转站。不在线、登录过期、主人不让用，各有各的说法，不算"连不上"。
   - 这时卡片里"连不上的原因"（§6.8）写"阿杰那边连不到中转站，可能是公司或学校的网络拦着"。我有自己的中转站时，下面一句"把你的中转站拖到这条线上试试"：它在别的机房、用别的端口，可能连得到。没有就写"换个网络试试"。
   - 理由：平时直接连不上，都会经公共中转站，写"经香港中转"，不吓人。用户看到"连不上"时，一定是真的连不上，而且知道能怎么办：换个网络，或者拖一个自己的中转站上来。这正是场景 2 那个拖法还留着的用处。
3. **问不到地点的中转站，句子里怎么叫。** 推荐：有名字就叫名字，只有地址的叫"我的服务器"（别人的叫"阿杰的服务器"），地址只留在小球、卡片标题和"更多"里。
   - "经 198.51.100.4 中转"对普通人是一串数字，看不出是谁的、在哪儿；"经我的服务器中转"一眼就懂，而且和小球第二行、卡片第二行说的是同一件事。
   - 改了名就用名字（"经公司机房中转"），所以卡片里名字是地址时，单击就能就地改，不用额外提醒。
   - 只有一种情况会分不清：同一个人有两台都没改名的服务器，句子里都叫"我的服务器"。这时看小球和卡片标题上的地址能分开；真碰到了，再考虑在句子里带上地址的最后一段（"我的服务器（.4）"）。

### 6.13 本地网络权限没拿到（M5）

> **用户 11-10 看过，按推荐定**（M5 第 1 批，和窗口、托盘一起交）。引擎线 11-09 加了问题码 `local-network`：macOS 的"本地网络"权限不让引擎往家里同一个路由器下的设备发包，这些设备只能绕到外面再回来，或者经中转，能用但慢。引擎在局域网设备一回应就撤掉这个问题。根本解决在 M6（引擎装进应用包、由用户点"允许"，或者以 root 跑），不在这一批。

- **做法和 Clash 那条一样**（§6.8）：只在引擎报了才出现；标题区右边、小球叠左边一枚琥珀色小胶囊："本地网络权限没拿到"。不放在画布上，不盖设备。
- **点它**，右上角弹出卡片（和设备卡片同一层）：
  - 第一句（粗）："Deneb 还没拿到本地网络权限"。
  - 第二句："和这台电脑连着同一个路由器的设备（比如家里的 NAS），现在要绕到外面再回来，或者经中转。能用，只是慢一些。"
  - 第三句，这一批（M5）：引擎还不在应用包里，系统设置里没有它的开关，只能写"等 Deneb 正式版，装好时点一次'允许'就好"，下面只有"知道了"。M6 以后（引擎在应用包里，系统设置里有 Deneb 的开关），换成"在系统设置的「隐私与安全性 › 本地网络」里打开 Deneb"，下面"知道了"和"去系统设置"（直接打开那一页）。
  - 推荐：这一批不放"去系统设置"按钮。系统设置里没有能打开的开关，按钮只会让人白跑一趟。
- **"知道了"**：胶囊和卡片一起收起，同样的情况下次不再提示（和 Clash 那条一样）。
- **自己好了**：家里的设备一回应，引擎撤掉这个问题，胶囊缩小淡出；卡片开着就跟着收起。不弹"已修好"之类的提示。
- 词：Deneb 里"局域网"指的是我们的虚拟局域网，所以这里不说"同一个局域网"，说"连着同一个路由器"。

### 6.14 导出诊断包、别的代理软件（M6）

> **用户 11-10 看过，按推荐定**（M6 第 1 批，和首次打开一起交）。诊断包里装什么由引擎线定（i7 的引擎部分），这里只定界面。客户端已接上真的：导出诊断包由引擎打包（`GET /v1/diagnostics`），存进这台电脑的「下载」；代理软件，引擎只说有别的程序接走了连接、说不出是哪个，窗口自己在正在跑的程序里找：认出 Clash、Surge、v2rayN 就写它的名字和它的写法，认不出写"代理软件可能挡住连接"。

**导出诊断包**（i7）

- 在"这台电脑"的卡片里，点开"更多"，最下面一行文字按钮"导出诊断包"，下面一行灰字"里面有版本、网络状况和最近的连接记录，没有密钥，也没有你传的东西"。
- 点了：这一行变成"正在收集…"（转圈，一般一两秒），收好后提示条"诊断包存到了「下载」 · 在访达中显示"（Windows 是"在资源管理器中显示"，Linux 是"打开所在文件夹"）。文件名"Deneb 诊断包 2026-11-09 23-41.zip"。
- Deneb 不替用户上传，要给谁由用户自己发。

**别的代理软件**（i6，和 §6.8 的 Clash 那条同一套）

- 引擎能认出是哪个软件时，胶囊写它的名字："Surge 可能挡住连接""v2rayN 可能挡住连接"；认不出写"代理软件可能挡住连接"。
- 卡片里写在那个软件的哪儿、加哪一条，按它自己的写法：
  - Clash、Clash Verge、mihomo：在规则里加 `IP-CIDR,10.67.0.0/16,DIRECT`。
  - Surge：在「规则」里加 `IP-CIDR,10.67.0.0/16,DIRECT`。
  - v2rayN：在「路由设置」的「直连」里加 `10.67.0.0/16`。
  - 认不出的：让 `10.67.0.0/16` 直连，不经过它。
- 下面"知道了"和"复制规则"。Deneb 只给出规则，不改它们的设置（§6.8）。地址段以引擎报的为准。

#### 菜单栏在客户端里（M2 第三批）

> 上面是定稿的大框；这里补客户端的细节。先在演示模式里做出来，用户看过再定稿。

- **图标**：18 点的模板图（黑色加透明，系统自己染色），18 像素和 36 像素各画一张，三种：睁眼的小星（§15）；右下角多一个小点（小点外面留一圈空，免得糊在一起）；闭眼、变淡（一半的透明度）。2026-11-13 前是亮星、加点的亮星、空心星。
  - 有事要我处理时带小点：有设备或人等我同意、我的设备要重新登录、有设备连不上、有人按名字邀请我。
  - 闭眼的小星：所有局域网都暂停了，或者这台电脑上的 Deneb 没在跑。
  - 单击开或关面板，右键也一样（M2 先不做系统小菜单：退出 Deneb 会让人以为连接也断了，要想好怎么说再加）。
- **面板**：宽 320，圆角 20，系统阴影，白底（深色时深底加细边），挂在图标正下方，离菜单栏 6。高度跟着内容走，最高 560，再多就在面板里滚动。打开时从图标那里稍微放大、淡入（160 毫秒），收起时反过来。
  1. **头部**：这台电脑的设备块（小号）、名字，下面一句总状态，前面一个小圆点（绿 / 灰 / 琥珀）："都连上了"、"2 台连不上"、"正在连接…"、"1 台不在线"、"都暂停了"、"Deneb 没在运行"（这时下面只剩"打开 Deneb"）。照实说，用的词和卡片里状态那句一样：都连上了才写"都连上了"；有设备连不上写"N 台连不上"（琥珀），有设备不在线写"N 台不在线"（灰）；几种都有时，按卡片的先后只说最要紧的：连不上、正在连接、不在线。菜单栏图标照旧：连不上本来就算"要你处理"，带小点；不在线不是要你处理的事，不带。（2026-11-08 主会话定）
  2. **要你处理**：有事时才有这一组，每行一件事、右边一个按钮。最多显示 3 行，再多写"还有 2 件 · 打开 Deneb 看"。
     - 等我同意的设备："阿杰的树莓派想加入周末联机" · 同意
     - 等我同意的人："小林想加入周末联机" · 同意
     - 我的设备要重新登录："我的游戏主机需要重新登录" · 续上
     - 别人按名字邀请我："Leo 邀请你加入桌游夜" · 看看（打开主窗口，弹出邀请卡）
     - 连不上的设备："Mia 的 MacBook 连不上" · 看看（打开主窗口，选中它，卡片里有原因）
     - 点"同意"或"续上"，这一行原地变成"已同意阿杰的树莓派 · 撤销"，4 秒后收起；撤销就回到原来那一行。和主窗口一样，同意是先在界面上生效，行收起时才真正发出去。
  3. **局域网**：每个局域网一行：成员小圆点、名字、一句状态（"4 台都连上了" / "6 台，5 台连上了" / "已暂停" / "等 Leo 同意你加入"），右边一个小开关（和侧边栏同一个）。拨开关就是暂停或恢复，面板、侧边栏、画布同时变。"等同意"的局域网没有开关。点这一行（开关以外）打开主窗口并切到这个局域网。
  4. **底部**："打开 Deneb"，点了收起面板，把主窗口叫到最前面。
  - "共享给我"要等 M3 有了分享再加。
  - 点面板外面、按 Esc，面板收起。面板和主窗口是同一份数据，一边改了另一边立刻跟上。
- **演示和录帧**：录帧时在面板上方画一条假的菜单栏，只为看清面板从哪儿弹出来；产品里就是系统的菜单栏。
- **产品里（接真实数据）**：图标是系统菜单栏里的状态栏项，面板是挂在图标下的无边框面板（MyGo 的 Flyout），浮在别的应用上面、不抢焦点，里面画的就是上面这块面板，数据和主窗口同一份。
  - 每次点开都新建一块面板，整块连同系统阴影淡入 160 毫秒，收起时淡出。真面板不做演示里的轻微放大：系统阴影跟着窗口，内容一缩放，阴影就和面板对不上。
  - 面板高度跟着内容变；超过 560 时，中间"要你处理"和"局域网"两组在面板里滚动，头部和"打开 Deneb"不动。
  - 关主窗口（×）不退出：窗口藏起来，Deneb 留在菜单栏（引擎本来就一直在跑）。面板里点"打开 Deneb"，或者点 Dock 图标，窗口回来；⌘Q 才退出。窗口藏起来时，它的提示条里扣着的操作当场发出去。
  - 面板里点的事没办成（比如这台电脑的引擎太旧，还不能暂停），头部下面多一行灰底小字，写和主窗口提示条同一句话，4 秒后收起；开关保持原样。
  - 还没登录时总状态写"还没登录"，图标是闭眼的小星（这台电脑什么也连不了）；登录了、数据还没到时写"正在连接…"。
  - 深色时系统自己给面板描一圈细边，面板不再画边。
  - 图标图片是 36 像素（18 点的两倍），星在中间占 16 点：MyGo 把菜单栏图标统一定成 18 点高，这样图不会被缩放发虚。

### 7.2 Windows、Linux 的窗口和托盘（M5）

> **用户 11-10 看过，按推荐定**（M5 第 1 批，交付在 `M5-Windows和Linux/第1批-托盘和窗口/`）。先在演示里做出来，用户看过再写进客户端，再到 Windows 测试机和 Linux 虚拟机上验。依据：实现计划 §3 M5，§8 只留两处差异，MyGo 0.7.4 的文档（`docs/frontend.md` 自绘标题栏、`docs/windows.md` 弹出面板、`docs/menus.md` 托盘）。托盘图标先沿用三颗星，logo 定了再换。11-11 按系统改了两处，在虚拟机上验出来的：Linux 顶栏的星没有双击，Ubuntu 上窗口是直角（都在下面写明）。

**MyGo 在这两个平台上能做到的**（2026-11-09 查的）

| | Windows（11） | Linux（Ubuntu 26.04，GNOME，默认 Wayland） |
| --- | --- | --- |
| 藏起标题栏、自己画标题区 | 能。窗口按钮（最小化、最大化、关闭）留在右上角，照 Windows 11 的样子画，高度跟着我们给的标题栏高度；指着最大化会出贴边分屏的布局 | 能。按钮是 GTK 自己的，放在桌面设置的位置（Ubuntu 默认在右边，三个圆按钮），在我们给的标题栏高度里居中 |
| 圆角、阴影、拖边缩放 | 系统给：圆角 8，系统阴影，四边都能拖 | 系统给阴影和一圈细边，外圈几个像素拖得动；窗口是**直角**，不跟主题的圆角（11-11 查的，见下面"Ubuntu 上是直角"） |
| 托盘图标 | 通知区（任务栏右下角）。要自己按任务栏深浅给黑星或白星（`Tray.Dark` 告诉深浅）。新图标默认收在"^"里，用户拖出来才一直看得见 | AppIndicator（要 `libayatana-appindicator3`；Ubuntu 默认装着并开着扩展，原版 GNOME 没有）。单击只能出系统菜单；双击照 MyGo 的文档能交给程序（`OnClick`），但要系统的 libayatana 把点击交出来，Ubuntu 26.04 的不交（11-11 改，见下面"没有双击"） |
| 挂在图标旁的自绘面板 | 能：知道图标在哪，面板贴在图标正上方，系统给圆角 8、细边和阴影（我们不画圆角和边） | 不行：AppIndicator 不告诉点了哪儿、图标在哪儿；Wayland 下程序摆不了自己的窗口，面板只能出现在屏幕正中，离图标很远 |

**窗口**（三个平台同一套，只差按钮位置和圆角，§8）

- 都用系统的窗口、藏起标题栏（M1 起 macOS 就是这样，§8 第一行一起改）：圆角、阴影、拖边缩放、贴边分屏都交给系统，各平台的人用起来顺手。
- macOS 的按钮在左上角，压在侧边栏顶上，标题区照旧。Windows、Linux 的按钮在右上角，会压到标题区右边的小球叠和"邀请朋友"，所以右边那一栏顶上留出一条（Windows 32 高，Linux 40 高，按钮就在这一条里），标题区整个往下挪这一条。这一条和侧边栏顶上那段空白一样，按住能拖动窗口，双击是最大化（系统给的）。
- **Ubuntu 上是直角**（11-11 查了 MyGo 0.7.4 的源码；用户 11-12 看过 M5 第 2 批，按推荐定）：Wayland 上 GTK3 自己给窗口画阴影和一圈细边，也从那儿拖边缩放；窗口里的画面是一块铺满的 GtkGLArea，GTK3 不按主题的圆角裁它，所以四个角是直的。Deneb 这边改不了：换成透明窗口、自己在画面里画圆角，MyGo 就不让 GTK 画装饰，系统的阴影和外圈拖边一起没了，得不偿失；要圆角，得 MyGo 让这块画面带透明，按主题的半径把四个角留空。Windows（8）和 macOS 照旧是系统的圆角。
- 别的都不变：侧边栏、标题区、画布、卡片、托盘、提示条，大小、颜色、动效逐像素一样。字体是内嵌的，不用系统字体，三个平台字形一样。
- 关窗口（×）不退出，和 macOS 一样：窗口藏起来，Deneb 留在通知区或顶栏，连接照常（引擎本来就在后台跑）。Linux 没有托盘时（原版 GNOME），关窗口就退出界面，连接照常，从应用列表再点开就回来。

**Windows 通知区**

- **图标**：16 点，彩色（2026-11-13 用户要的），三种和菜单栏一样：睁眼的小星；有事要处理时右下角多个橙色的点；都暂停了或 Deneb 没在跑时闭眼、变灰。任务栏深浅各一版，跟着系统切换；按托盘所在显示器的缩放给 16、20、24、32 像素的图（§15.3）。Linux 用深色任务栏那版。
- **单击**：在图标正上方弹出面板，面板底边离任务栏 12。面板和菜单栏的那块完全一样（宽 320，同一份内容：这台电脑、要你处理、局域网的开关、共享给我、打开 Deneb），只是圆角、细边和阴影交给 Windows（圆角 8）。出现时淡入，同时往上浮 8（160 毫秒），收起时反过来。点面板外面、按 Esc、再点一次图标，都收起。
- **右键**：和单击一样出面板。不放系统小菜单（和菜单栏同一个理由：菜单里放"退出"会让人以为连接也断了，§7.1）。
- **第一次关窗口**：图标上方弹一张小提示（和面板同一个样子，一行字）："Deneb 还在这儿，连接照常。点这颗星就能打开窗口"，6 秒后或点一下就收起，以后不再出。Windows 默认把新图标收在"^"里，这句话让人知道去哪儿找；图标在"^"里时，这张提示贴着"^"，后面加一句"可以把它拖到任务栏上"。

**Linux 顶栏（AppIndicator）**

- **图标**：顶栏右边，系统图标的左边。Ubuntu 的顶栏是黑的，用白星，三种和上面一样。
- **单击**：出系统菜单（样子是系统的，我们只定里面有什么）：
  1. 第一行灰字：总状态，和面板头部同一句（"都连上了""2 台连不上""都暂停了"）。
  2. 有事要处理时，一件事一行（"Leo 想加入周末联机…"），点了打开窗口、选中那件事；菜单里不直接"同意"，因为系统菜单点完就关，撤销没地方放。
  3. 每个局域网一行，前面一个勾，写名字和状态（"✓ 周末联机 · 4 台都连上了"）；点一下就是暂停或恢复，勾跟着变，和面板、侧边栏的开关是同一件事。
  4. "打开 Deneb"。
- **没有双击**（11-11 按系统改；用户 11-12 看过 M5 第 2 批，按推荐定）：Ubuntu 26.04 的 libayatana-appindicator3（0.5.94）不把点击交给程序，GNOME 的 AppIndicator 扩展每次单击都直接出菜单，双击什么也不做，所以窗口从菜单最后一行"打开 Deneb"打开。这是系统的限制：要双击，得换成 libayatana-appindicator-glib，MyGo 0.7.4 不支持。（M5 第 1 批写的是"双击直接打开窗口"，M5 在虚拟机上验时发现做不到。）
- **为什么不做面板**：面板只能出现在屏幕正中，和点的地方对不上，像弹了个莫名其妙的窗口。系统菜单虽然素一点，位置、键盘、深浅色都对，几项最常用的事（看状态、暂停、打开窗口）在菜单里都能做；要细看就打开窗口。要选的话：单击出一个贴着顶栏右边的小窗口，只在 X11 下摆得准，Ubuntu 默认的 Wayland 下摆不了，所以不推荐。

**演示里**：Windows、Linux 的窗口按钮由系统画，演示里照着样子画一份，只为看清标题条；任务栏、顶栏、系统菜单也是照着画的，产品里都是系统自己的。

### 7.3 首次打开的引导（M6）

> **用户 11-10 看过，按推荐定**（M6 第 1 批，交付在 `M6-装得上/第1批-首次打开/`）。客户端已接上真的：登录在窗口里填邮箱和验证码，窗口照浏览器那样交给服务器的登录页，用和引擎一样的证书指纹核对服务器（只认得 Deneb 自己的服务器；别人自己架的服务器照旧在浏览器里登录）；装网卡这一步只在 Windows 上出现（引擎线的新流程：先停下窗口自己起的引擎，再以管理员身份装成系统服务，弹一次 UAC；没装上就照旧用用户态引擎）。macOS 装网卡那条路等有 Apple 开发者账号再定（i1 搁置），这一步在 Mac 上不出现；Linux 的 deb 装的时候已经装好了，也不出现。别的账户打开 Deneb 时，窗口说用户选的 B："Deneb 在这台电脑上是给另一个账户用的，请换回那个账户"。

- **样子**：没有侧边栏，窗口正中一列，宽 360，离顶 150，最上面是 Deneb 的星和三个小圆点（登录、装网卡、第一个局域网），走到哪一步哪个点亮。每一步从右边滑进来（16，淡入，220 毫秒），上一步往左滑出。白底（深色时深底），用卡片、按钮、输入框的现有样子，不另画插图。
- **1 登录**：标题"登录 Deneb"，一句"用邮箱就行，我们发一个 6 位验证码"。只有一个邮箱输入框和"发验证码"。发出去后，同一张卡片里换成"验证码发到了 kittors@gmail.com"（完整的邮箱，§14.14）和 6 个小格，填满第 6 位就自己验证，粘贴也能一次填满，没有"确定"按钮。错了，格子下面一行红字"验证码不对，再看一眼"，格子轻轻抖一下（不弹框）。下面灰字"没收到？60 秒后可以重发"，倒数完变成能点的"重发"。验证通过：打一个勾，0.6 秒后到下一步。
- **2 装网卡**：标题"给这台电脑装一块网卡"。正文"装上以后，这台电脑上的任何程序（浏览器、远程桌面、游戏）都能直接连到局域网里的设备，就像在同一个 Wi-Fi 里。"下面一句说清要什么权限（照平台说）：
  - macOS："系统会请你在「登录项与扩展」里打开 Deneb，输一次开机密码。"
  - Windows："Windows 会弹一个窗口问你，点「是」就行。"
  - Linux：deb 包装的时候已经装好了，这一步不出现。
  - 按钮：主按钮"装上"，下面文字按钮"先不装"。点"装上"：按钮变成"等你在系统里点允许…"（转圈），系统那边批了，打一个勾写"网卡装好了"，0.8 秒后到下一步。mac 上 6 秒还没批，下面多一行"没看到？打开系统设置"（点了直接打开那一页）。用户在系统里拒了：回到"装上"，上面一行灰字"没装上也能用，在 Deneb 里点「打开」照样能连"。
  - 点"先不装"：一行灰字"也能用：在 Deneb 里点「打开」就能连；以后点窗口右上角的「还没装网卡」就能装"，分号后换行，两行居中，1 秒后到下一步。（M6 第 2 批改：原来写"以后在设置里随时能装"，Deneb 没有设置页；能装的地方见下面"已登录的电脑装网卡"。）
- **3 第一个局域网**：标题"建一个局域网，或者加入朋友的"。两张并排的大卡片，点哪张都行：
  - "新建局域网"：小图是这台电脑的设备块和一个加号，下面一句"先只有这台电脑，之后把别的设备拖进来、邀请朋友"。点了就建一个"kittors 的局域网"（名字以后在局域网卡片里改），引导淡出，露出平常的窗口，画布上这台电脑弹出来，托盘里是我别的设备，写着"拖出来，加进局域网"。
  - "加入朋友的"：小图是一个链接。点了，这张卡片原地展开成一个输入框"把邀请链接粘贴到这里"（剪贴板里有 Deneb 的邀请链接就自动填上），旁边"加入"。点了先看邀请卡（§6.7，谁邀请你、加入哪个局域网），再点"加入"进去。
  - 最下面文字按钮"以后再说"：直接进窗口，画布空着，写"还没有局域网"（现有的空画布）。
- **只出现一次**：这三步做完（或者"以后再说"），这台电脑记下来，以后打开不再出现。登录过期、换了账号，只出第 1 步。

#### 已登录的电脑装网卡（M6 第 2 批）

> **用户 11-12 看过，都按推荐定**（M6 第 2 批，交付在 `M6-装得上/第2批-已登录的电脑装网卡/`）。Windows 测试机上查出来的（a1，11-11）：已经登录、又已有局域网的电脑，打开 Deneb 不出引导，窗口里也没有别处能装网卡；重装 Deneb 以后（这台电脑的身份还在），或者引导里点了"先不装"，就一直停在用户态。Windows 上用户态的引擎只走中转（不开 UDP 端口，免得第一次打开就弹防火墙框，引擎线 11-11），所以这件更要紧。

- **什么时候出现**：只在 Windows 上（Mac 装网卡等开发者账号；Linux 的 deb 装的时候已经装好），这台电脑登录了、引擎还没有网卡、引导不在屏幕上时。
- **做法和本地网络那条一样**（§6.13）：标题区右边、小球叠左边一枚琥珀色小胶囊"还没装网卡"。不放在画布上，不盖设备。
- **点它**，右上角弹出卡片（和设备卡片同一层）：
  - 第一句（粗）："这台电脑还没装网卡"。
  - 第二句，为什么要装："装上网卡以后，能直接连到局域网里的其他设备，不用绕中转站，浏览器、游戏也都能直接用。"（正好两行，断在逗号上）
  - 下面一个带锁的灰底小框，意思和引导第 2 步那句一样，短一点，一行放得下："Windows 会弹窗问你，点「是」就行。"
  - 最下面"以后再说"和"装网卡"。
- **点"装网卡"**：和引导第 2 步走同一条路（先停下窗口自己起的引擎，再以管理员身份装成系统服务，Windows 弹一次 UAC）。
  - 按钮那一行换成转圈"等你在系统里点允许…"。装的时候引擎要停一下，标题区那句总状态写"正在装网卡…"（灰点），不写"连不上这台电脑上的 Deneb"。
  - 装好了：那一行换成绿勾"网卡装好了"，1.2 秒后胶囊和卡片一起收起（缩小淡出，和 §6.13 的"自己好了"一样），总状态回到平常那句。不另弹"已装好"的提示条。
  - 在 UAC 里点了"否"，或者没装上：回到"以后再说"和"装网卡"，上面多一行灰字"没装上也能照常用，想装时再点「装网卡」"。
- **"以后再说"**：胶囊和卡片一起收起，这次不再出现；下次启动 Deneb（一般是重新开机以后）还会出现，直到装上。
  - 推荐这样：只走中转比本地网络那条更影响快慢，不该点一次就再也不提；一天提一次也不算催，胶囊不弹窗、不挡画布，不点也没事；也不用另找地方放"装网卡"。
  - 没选的另一种：点了以后 3 天不出现，同时在"这台电脑"卡片的"更多"里常放一行"装网卡"，想早点装从那儿装。多一个入口、多一条规则，不推荐。
- **关闭（×）**：只收起卡片，胶囊还在。
- **网卡已经在了**（引擎是系统服务），胶囊不出现；开着的时候网卡装上了，胶囊缩小淡出，卡片开着就跟着收起。
- 引导第 2 步点了"先不装"，进到窗口时胶囊就在："以后点窗口右上角的「还没装网卡」就能装"说的就是它。

## 8. 三平台一致

| 方面 | 做法 |
| --- | --- |
| 窗口外形 | 系统的窗口、藏起标题栏（`TitleBarHidden`），标题区自绘；圆角、阴影、拖边缩放、贴边分屏交给系统（M1 起就是这样，§7.2） |
| 毛玻璃 | glass 插件在窗口里自己画，**不用**窗口级 `Vibrancy`（Linux 没有） |
| 字体 | 内嵌，不用系统字体 |
| 颜色 | 固定品牌色，不跟随系统强调色 |
| 控件 | 全部自绘（MyGo 本身就是这样） |
| 平台差异 | 只保留两处：窗口按钮的位置（macOS 在左，Windows / Linux 在右；在右边时主区顶上多一条放按钮，标题区往下挪这一条，§7.2），以及圆角（窗口本身的圆角是系统的，Ubuntu 上是直角，§7.2；我们画的圆角，MyGo 在 macOS 上是连续曲率，其他平台是四分之一圆，肉眼几乎看不出） |

## 9. 场景脚本（第三版）

每个场景是一个可交互的页面（`design/demos/0N-*.html`），和小样 `sample.html` 用同一套界面：窗口、侧边栏、标题、画布、设备块、连线、设备卡片、底部托盘、提示条（代码在 `design/demos/v3/`）。窗口外面底部有一条很小的 demo 控制条：上一个 / 下一个场景、模拟外部事件的按钮、重播、深浅色。它不属于产品界面。

所有文案都是日常说法（见 §2）。连线上的状态写在一枚小胶囊里，放在线的中点，状态变化时文字平滑切换，稳定 2 秒后淡出。

### 场景 1 · 先直接连，连不上就经中转（`01-direct-relay.html`）

**画面**：侧边栏选中"我的设备"。画布上左边是"这台电脑"（家里），右边是"工作室主机"（公司），两台都是我的（蓝色）。名字下面第二行写所在的地方。

**能直接连时**（控制条：公司网络 = 普通）：
1. 两台设备之间出现一条灰色点线，点线在缓慢流动，中点胶囊写"正在连接…"。
2. 约 1.4 秒后，轨道从两端长出来，在中点接上，接上处闪一下，光开始流动。胶囊变成"直接连上 · 很快"，两秒后淡出。"工作室主机"第二行变成"公司 · 直接连上"。

**连不上时**（控制条：公司网络 = 有防火墙）：
1. 点线流动约 2.4 秒，胶囊依次写"正在连接…""直接连不上，改走中转"。
2. 两台设备中点下方弹出"香港"中转站，Bouncy 落位。
3. 点线淡出，两段轨道依次从设备长到中转站，光开始流动，到中转站停一下再走。胶囊写"经香港中转 · 慢一点"。

**网络变了**（控制条按钮）：直接连着时按下，直连轨道里的光先停，胶囊写"网络变了，改走中转"，中转路线接上后光不断流。再按一次（"网络恢复"），直连轨道重新长出来，中转站缩小淡出。整个过程不出现"断开"。

**交互**：单击设备或胶囊，右侧弹出设备卡片，用一句话说明现在怎么连的（"直接连上，很快" / "经香港中转，慢一点但能正常用"），"更多"里才有延迟毫秒数和地址。画布不为卡片挪动（§6.3）：卡片在自己的一层里盖住工作室主机也不让位，点画布空白处或 × 就收起。

**挪设备**（§6.2）：两台设备都能拖。连线像软绳一样跟着走，胶囊跟着线走；放到另一台上，被压的那台往旁边让一下，放下的这台吸到它来的那一侧的空位；推到窗口边上，停在边上，名字也完整留在画面里。中转站出现时找两台设备中间下方的空位，用户挪过它，下次就出现在用户放的地方。经过中转站的连线不能压住任何设备的名字，也不穿过别的设备块：中间下方那个空位不行，就在它周围由近到远找一个行的；它自己挑的位置每次出现时都重新看一遍（设备可能挪过），用户亲手放的位置不动。（M2 真机验收第 13 条：中转站在 NAS 左下方时，连线曾从 NAS 的名字中间穿过）

### 场景 2 · 连不上？拖一个中转站进来（`02-drag-relay.html`）

**画面**：局域网"周末联机"。Mia 的 MacBook（在酒店）和阿杰的台式机（用手机热点）互相连不上：两者之间是一条灰色点线，中点胶囊写"连不上"。底部托盘写"中转站"，放着三个白色小球：香港（我的服务器）、家里的 NAS（Mia 的设备）、东京（公共）。

**交互**：
1. 按住托盘里的"香港"拖出来，小球放大成正常大小跟着指针走。靠近点线时，点线两端弯向小球，离得越近越明显。
2. 松手：中转站 Bouncy 落位，两段轨道从 Mia 和阿杰长到中转站，光开始流动，胶囊变成"经香港中转"，两台设备第二行变成"能连上了"。
3. 再把中转站拖回托盘，就是移除：轨道收回，又变回点线；托盘上方出现"已移除香港 · 撤销"。撤销后回到原位。
4. 单击托盘里的小球，它自己飞到点线的中点（不用拖）。已经有中转站时放入另一个，就是替换：旧的先飞回托盘。
5. 松在画布外或按 Esc：小球弹回托盘。
6. **挪设备**（§6.2）：Mia、阿杰、这台电脑都能拖，中间的点线和"连不上"胶囊跟着走；中转站的推荐位置跟着两个人的位置变。托盘只收中转站，设备拖不进托盘：到托盘上方就停住，托盘说明原因（§6.2）。

### 场景 3 · 一台电脑同时在几个局域网（`03-multi-network.html`）

**画面**：
- 侧边栏"局域网"下面依次是"全部"（选中）、"工作室"（带开关）、"周末联机"（带开关）。
- 画布中间是"这台电脑"，名字在上方，第二行写"在 2 个局域网里"。左右各一块浅灰圆角区域，左上角写局域网的名字和成员的小圆点：
  - 左边"工作室"：dev-db、CI 构建机（都是小林的）、阿杰的台式机；
  - 右边"周末联机"：Mia 的 MacBook、阿杰的 NAS、我的游戏主机。
- 每块区域里的设备排成一道朝向"这台电脑"的弧，连线呈扇形散开，不穿过别的设备和名字。连线的弯曲方向随位置连续变化，设备移动时线不会突然翻面。
- dev-db 第二行写"已连接 2:14:08"，每秒走一次。

**交互**：
1. **聚焦**：悬停侧边栏某个局域网，它的区域保持原样，其他区域和连线降到 35%，光照常流动。
2. **暂停**：关掉"周末联机"的开关，它的连线带着一个亮点退回"这台电脑"，原处留下一排点，区域右上角显示"已暂停"，设备变灰，第二行写"已暂停"。"工作室"不受影响，dev-db 的计时照走。标题下写"周末联机已暂停，其他照常"。再打开，轨道从"这台电脑"重新长出去。
3. **挪设备**（§6.4）：设备在自己的局域网里随便摆，区域永远包住它的设备（留出标题的位置），跟着伸缩。按住"我的游戏主机"拖起来，设备块连同名字跟着指针走，连线跟着走，原位不留影子；靠近"工作室"区域（或侧边栏那一行）时它亮起蓝色描边。拖到侧边栏上方时设备块缩小，免得盖住那一行。松在"工作室"里就停在松手处，工作室区域长大把它包进来，周末联机区域缩小；如果原来的局域网是暂停的，点线变回流光。底部提示"已把我的游戏主机挪到工作室 · 撤销"，撤销后回到原来的位置和状态。拖到区域外的空白处就是撤出这个局域网，同样可以撤销。别人的设备（比如阿杰的台式机）拖不出自己的区域：到区域边上就停住，区域边上写"这是阿杰的设备，只有阿杰能移出"（§6.2）。
4. **挪区域**：按住区域的空白处，整块局域网连同设备一起走，抬起时带阴影，连线跟着走；松在别的区域或"这台电脑"上会吸到最近的空位；拖不出窗口；按 Esc 回到原处。"这台电脑"也能拖，它不会被放进任何一块区域。
5. **加入**（控制条"收到邀请"）：窗口右上角（标题区右边的空位）弹出卡片"Leo 邀请你加入「桌游夜」"，卡片上有 Leo 的小球、"以后再说"和"加入"。点"加入"后，画布上已有的东西一起往上让位（够用就停），新区域从下方淡入，设备依次弹出，轨道从"这台电脑"长出；地方不够时，新区域找最近的空地。侧边栏插入一行，背景亮一下再褪掉；"这台电脑"第二行变成"在 3 个局域网里"。

#### 场景 3 在客户端里（M2）

> 上面是 HTML demo 的剧本；客户端照着做，这里补客户端才有的几处。M2 的设计稿，先在演示模式里做出来，用户看过再定稿。

- **侧边栏**：
  - 有两个以上局域网时，"局域网"下面第一行是"全部"，前面是"人"的图形；点它，画布换成"全部"视图。窗口打开时还是上次看的那个，不默认"全部"。
  - 每个局域网一行，末尾一个小开关（比卡片里的开关小一号）：开着就是在连，关上就是暂停。有东西等我同意时的小蓝点在开关左边；"等同意"的局域网没有开关。点开关只是暂停或恢复，不切换画布。
  - 悬停某个局域网的行就是聚焦（只在"全部"视图里有效果）：其他区域、它们的设备和连线降到 35%，光照常流动；从一行移到另一行，聚焦直接跟过去；离开这几行，稍等一下（约 0.1 秒）全部恢复。拖着东西时不聚焦。
- **暂停**：
  - 关掉开关后，这个局域网在这台电脑上暂停：它的连线带着亮点退回这台电脑，原处留下一排点，设备变灰，第二行写"已暂停"，同一台设备在别的局域网里不受影响。
  - 单个局域网的画布上，标题下写"已暂停，打开开关就恢复"，整张画布照常能看、能点；"全部"视图里这块区域右上角写"已暂停"，标题下写"周末联机已暂停，其他照常"，全都暂停时写"都暂停了，打开开关就恢复"。
  - 再打开，轨道从这台电脑重新长出去，末端带着亮点。
- **"全部"视图的布局**：
  - 标题是"全部局域网"，下面一句"2 个局域网，8 台设备都连上了"（同一台设备在两个局域网里只算一台）。标题区没有小球叠和"邀请朋友"，因为不是某一个局域网。
  - 这台电脑在中间，名字在上方，第二行写"在 N 个局域网里"。
  - 前两个局域网分在左右两边；第三个放在这台电脑下方、左右两块中间；后来加入的局域网，区域找离它最近、不压别的区域和这台电脑的空地（M2 先做到 3 个排得好看，4 个起尽量不重叠，画布放不下时还会挤在一起，计划风险里写过）。
  - 每块区域里，设备排成一道朝向这台电脑的弧；之后摆放照用户放的来，按"局域网 + 设备"记住，同一台设备在两个局域网里各有各的位置。
  - 区域永远包住它的设备，留出标题的位置，跟着设备伸缩（Smooth 弹簧）；区域的底色画在连线下面，线从这台电脑一直连进区域里的设备。
  - 一台设备在两个局域网里，就在两块区域里各出现一次（两个设备块），不算同名。
  - "全部"视图里不画中转站：经中转的连线直接连过去，第二行照样写"经香港中转"。
  - 点右半边的设备，卡片出在左边，免得盖住它；点这台电脑，卡片只写"这就是你正在用的电脑 / 在周末联机和工作室里"，开放什么、谁能用是每个局域网自己的事，回到那个局域网的画布里改。
- **在区域之间挪**：
  - 我的设备拖起来以后，第二行变成蓝字，说松手会怎样：在别的区域上写"松手，挪到工作室"（那块区域亮起蓝色描边），在所有区域外写"松手，移出周末联机"（连线变淡），在已经有它的区域上写"工作室里已经有了"（松手弹回原处）。
  - 松在别的区域里就是挪：先加进新的局域网，再从原来的撤出；它停在松手处，新区域长大把它包进来，原来的区域缩小；提示条"已把我的游戏主机挪到工作室 · 撤销"，撤销就反过来做一遍，飞回原来的位置。
  - 松在所有区域外的空白处就是撤出，在松手处缩小消失；提示条"已把我的游戏主机移出周末联机 · 撤销"，撤销后回到原来的位置。
  - 别人的设备能在自己的区域里挪，区域跟着它伸缩，最多超出原来的边一小段就停住；停住时区域下方写"这是阿杰的设备，只有阿杰能移出"，松手后字淡出。
  - 按住区域的空白处，整块区域连同设备和连线一起走，抬起时带阴影，拖不出画布；松在别的区域或这台电脑上，它滑到最近的空地。
  - 这台电脑不在任何区域里，拖它只是换位置，别的设备不给它让位；经过区域时它的名字淡出，免得压住区域里的名字；松在区域上，它停到区域外最近的空位。
- **还没做的**（M2 第二批先不做，等用户看过再定）：拖到侧边栏那一行也算挪（画布裁掉了出界的部分，要先让拖着的设备能浮到侧边栏上）；拖到侧边栏上方时设备块缩小；按 Esc 让拖着的区域回到原处；新区域加入时已有的东西往上让位（现在是放进中间的空地）。

### 场景 4 · 管理员把设备分给某个人（`04-device-share.html`）

**画面**：桌面上两个窗口，界面和客户端用同一套令牌。
- 左边是浏览器里的管理后台：左侧浅灰导航（设备、成员、设备共享、设置），主区标题"设备共享"，灰色第二行"把设备拖到成员身上，就分享给他了"。下面两块浅灰的井：左边"工作室的设备"是设备块网格（GPU 主机、构建服务器、文件服务器、开发数据库、打印机、测试机，都是工作室的，同一种颜色）；右边"成员"是白色的成员行（小林、阿杰、Mia、Leo），每行是小球、名字和"N 台"。
- 右边是小林电脑上菜单栏里的 Deneb 面板（上方小字"小林的电脑 · 菜单栏里的 Deneb"），"共享给我"里列出已有的设备，每行写"工作室 · 直接连上"。

**交互**：
1. 把"GPU 主机"拖起来，它在网格里的位置空出来，设备块连同名字跟着指针走；离开网格时缩到六成，免得挡住成员行。经过成员行时，那一行亮起蓝色描边。
2. 松在小林那一行：设备块飞进她的小球，小球弹一下，"2 台"滚到"3 台"；一道光从她的小球出发，划一道弧飞进右边的面板，面板"共享给我"顶部插入"GPU 主机"，背景亮一下，带一个蓝色的"新"。
3. 拖给已经有它的人：那一行左右摇一下，"3 台"的位置短暂写"已经有了"，设备块飞回原位。
4. 单击成员行展开他已有的设备（小胶囊，每个带 ×），点 × 收回：胶囊缩掉，数字滚回去；面板里那一行折叠消失；后台底部出现"已收回 GPU 主机 · 撤销"。撤销后胶囊和面板里那一行都回来。
5. **排序**（§6.2）：设备块拖到另一个格子上就换到那个位置，其他格子用弹簧让开；成员行上下拖就是排序；顺序记在本机。
6. **人拖到设备上**：把 Mia 那一行拖到"打印机"上，同样是分享：打印机跳一下，Mia 的数字滚上去。拖着成员时跟着手的是一枚小胶囊（小球加名字），不挡住设备格子；经过的格子亮起蓝色描边。

### 场景 5 · 局域网里，各人管各人的设备（`05-lan-members.html`）

**画面**：局域网"周末联机"，成员有我、Mia、阿杰，画面和小样一样（香港中转站、阿杰的 NAS 经它中转）。底部托盘"拖出来，加进局域网"里是我还没加进来的设备：工作室主机、我的 NAS。Mia 和阿杰的连线往上、往外弯，因为这个场景里他们的第二行会变长，线不能贴着名字走。

**交互**：
1. **加入设备**：把托盘里"我的 NAS"拖进画布，松手的地方就是它的位置，轨道从"这台电脑"长出来，提示"已把我的 NAS 加进局域网 · 撤销"。单击托盘里的设备，它自己找一个空位。
2. **只开放一部分**：单击"这台电脑"，卡片里"开放给大家的"列出远程桌面、共享文件夹、命令行。关掉"命令行"后，用着命令行的阿杰那条连线里出现一小段红光，从阿杰那头跑向这台电脑，在门口散成一个小圈，阿杰的设备第二行写"命令行被关了"。（客户端：红光约 0.8 秒跑到这台电脑的门口，再散成一个小圈约 0.35 秒；第二行写"X被关了"4 秒，然后回到原来的样子。真实模式由引擎的 `cut` 事件触发；演示里阿杰的台式机在用这台电脑的远程桌面，关掉远程桌面就能看到。）
3. **不让某个人用**：卡片"谁能用"里点 Mia 的小球，小球变灰加斜线；Mia 到这台电脑的轨道带着亮点退回她那头，留下点线，她的第二行写"用不了这台电脑"。再点一次，轨道从两头重新接上。
4. **移出设备**：把"我的游戏主机"拖向托盘。靠近时托盘写"拖到这里，移出局域网"；到托盘上方时托盘亮起蓝色描边、写"松手，移出局域网"、末尾让出一个空格，设备块缩成托盘里的大小、名字淡出、连线变淡（预告"松手就断开"）。松手后轨道收回，设备块飞进那个空格，提示"已把我的游戏主机移出局域网 · 撤销"，撤销后它从托盘飞回原来的位置。拖到画布别处就是挪个位置。别人的设备也能挪位置，但拖不进托盘：到托盘上方就停住，托盘写"这是 Mia 的设备，只有 Mia 能移出"，松手后停在附近的空位。卡片里的"移出这个局域网"是不想拖时的单击替代。
6. **随便挪**（§6.2）：中转站也能拖，经它的连线跟着走；把我的 NAS 放到阿杰的台式机上，台式机往旁边让一下，NAS 吸到它来的那一侧的空位；把游戏主机推到窗口左边，它停在边上，名字也完整留在画面里。
5. **有人加入**（控制条"Leo 加入"）：标题右边的小球叠里弹出 Leo，他的设备从窗口右边弹进来落到右上角，先是流动的点线写"正在连接…"，接上后变成"直接连上 · 很快"，标题变成"4 个人，7 台设备都连上了"。

### 每个场景都要验收

- 光不从设备块和名字上面穿过；线和胶囊不压住名字；胶囊也不压住别的线。
- 每个节点都能拖（§6.2），拖着的节点浮在所有东西上面、拖不出窗口；放下后节点和名字都不重叠（§6.3）；连线像软绳一样跟着走，不突然翻面。
- 卡片、提示条、托盘、邀请卡不挡住正在操作的节点。
- 拖动的四个状态齐全（§6.1），松在无效的地方会弹回。
- 移除类操作都能撤销，撤销后回到原来的位置。
- 深色、浅色各录一遍，截图里没有被光标挡住的字。

## 10. MyGo 实现对照

小样 `design/demos/sample.html` 里的每种效果，都有对应的 MyGo 写法，没有用 MyGo 画不出来的东西。

| 效果 | demo 里的写法 | MyGo 写法 |
| --- | --- | --- |
| 设备块（彩色、带光泽） | 纵向渐变 + 内阴影 + 带颜色的外阴影 + 一块径向渐变光斑 | `Background(LinearGradient)` + `InsetShadow` + `Shadow{Color: 主人色}` + 子元素 `FillRadialGradient` |
| 人和中转站的小球 | 偏左上的径向渐变 | `FillRadialGradient` |
| 连线轨道 | Canvas 二次曲线描边 | `ui.Path.QuadTo` + `StrokePath` |
| 线里流动的光 | 沿弧长取一段，用渐变描边，加模糊 | `Path.Trim(s0, s1)` + `StrokePathGradient`，外面一层 `Blur` |
| 光到中转站停一下 | 每道光自己的时钟 | `p.Now()` + `AnimationFrame` |
| 连线从两端长出来 | 两段 Trim 同时变长 | `Path.Trim` + `Tween` |
| 悬停抬起、按下缩小 | CSS 过渡（弹性曲线） | `AnimatePose(ui.Pose{Y: -2}, ui.Snappy)` |
| 拖进来、落下 | pointer 事件 + 弹簧 | `Dragged` / `DragEnded` + `Drop[T]` |
| 设备卡片弹出 | 透明度 + 位移的弹性动画 | `Transition{Enter: ...}` |
| 开关 | 胶囊轨道 + 弹簧圆钮 | MyGo 自绘 `Toggle`，开时用 `primary` |
| "更多"展开 | 高度动画 | `Transition{Exit: &ui.Motion{Collapse: true}}` |
| 侧边栏 | 浅灰底 | `Background(well)`；需要透出时用 `glass.Glass{}` |
| 光退回设备（暂停、不让某人用） | 轨道的 Trim 从一端缩回，缩回的那头带一个亮点 | `Path.Trim` + `Tween`，亮点是 `FillRadialGradient` 小圆 |
| 一道光把东西"递"过去（场景 4） | 不描轨道，只跑一道更粗的光，到达时触发插入 | 同一套 `Path.Trim` 光；到达用 `p.Now()` 判断 |
| 区域随设备数伸缩、设备排进新位置 | 每个区域的矩形和每台设备的位置都挂在弹簧上 | 布局目标改变 + `ui.Smooth`（落位用 `ui.Snappy`） |
| 别人的设备按下摇一下 | 几帧左右位移的关键帧 | 连续的 `AnimatePose(ui.Pose{X: ±5})` |
| "2 台"滚到"3 台" | 旧数字上移淡出，新数字从下方进来 | 两个 `Text` 叠放，各自 `AnimatePose` + 透明度 |

## 11. 录屏自查流程

每个场景做完必须走一遍，问题全部修完才算完成。

1. **录制**：`design/tools/record.mjs` 启动一个独立的无头 Chrome（临时配置目录，不碰日常用的 Chrome），按页面里 `window.RECORDING` 的剧本模拟真实的鼠标操作（按下、拖动、松开都发真实事件；长距离移动带一点弧线）。页面在录制模式（`?record`）下由脚本推进时钟（`__advance`），CSS 过渡也跟着这个时钟走，逐帧截图，输出稳定 60 帧的视频。视频里会画一个假光标，看得出手在做什么。每次按下、松开之后，工具都会在原地补发一次指针移动，因为无头 Chrome 有时会把悬停状态残留在错误的元素上；这种残留只是录屏假象，真实浏览器里没有。
   - 命令：`node design/tools/record.mjs design/demos/0N-*.html [--theme light] [--scale 2] [--deliver]`
   - 联系表：`python3 -I design/tools/sheet.py <frames> <out.jpg> --from ms --to ms --step ms --crop x,y,w,h`
2. **自查**：从视频中抽出关键帧拼成一张联系表，逐帧对照下面的清单。
   - 运动检测：录屏同时生成 `trace.json`（每帧每个元素在画面上的位置、大小、透明度，以及每条线的弯曲），用 `node design/tools/motion-check.mjs <trace.json>` 检出跳变、抖动、闪烁、连线反复换弯、卡片重播入场（§6.6），结果必须为零；有问题就到对应时间点抽帧细看。
3. **修复**，然后重新录制，直到清单全部通过。
4. **交付**：最终的视频和关键状态截图（2 倍分辨率）存到 `~/Desktop/Deneb组网demo/`，文件名以时间戳开头，标题取页面 `RECORDING.title`。第三版以浅色为主，浅色不加后缀，深色加 `_深色`，例如 `20261107-1530_03-同时在几个局域网_加入桌游夜.png` 和 `…_加入桌游夜_深色.png`。被替换的旧文件挪进该文件夹的 `旧版本/`。

**清单**

- 布局：无重叠、无溢出、无截断；对齐网格；间距只用 §3.4 的值；圆角符合同心规则。
- 文字：没有多余的字，没有错别字；数字等宽，滚动时不抖。
- 动效：起止不跳；不闪烁；节奏符合 §5；弹簧不过度回弹；交错顺序符合直觉。
- 交互：拖拽四个状态齐全；悬停、按下有反馈；取消和撤销能回到原状态。
- 主题：深色、浅色各录一遍，对比度足够，玻璃在两种主题下都能看清。
- 叙事：不看任何说明，只看画面，也能明白发生了什么。

## 12. 待确认（demo 先按默认做）

1. **服务端由谁运营**（自己部署给大家用 / 开源让别人自己部署 / 两者都要）：demo 不涉及。"公共中继"暂时代表平台提供的中继。
2. **设备共享模式里的"管理员"**：场景 4 按整个服务的管理员处理，操作在网页后台。场景 5 里每个成员都能管理自己设备的加入、撤出和端口，发起人可以管理成员。
3. **中继从哪来**：三种都画（我的服务器 / 成员设备 / 公共中继），场景 2 里可以分别拖进来比较。
4. **把设备从一块区域拖到另一块，是"挪"还是"两边都在"**：demo 按"挪"做（§6.4），拖动从来不会悄悄多出一份；要两边都在，从侧边栏"我的设备"里再拖一次。如果大家更常要"两边都在"，可以改成：拖到两块区域之间（"这台电脑"站的那一栏）就表示两边都在。
5. **默认开放多少**：Tailscale 新建的网络默认全互通，收紧要写规则（调研 §0）。建议 Deneb 反过来：新加入的设备默认不开放任何服务，主人自己打开。场景 5 里"这台电脑"开着三项，是主人自己打开的结果。
6. **加设备、加人要不要先同意**：建议默认要发起人点一下：新设备、新成员先以"待同意"的虚线球出现，点一下才进来。M2 设计见 §6.7；规则已和控制线对齐（拥有者亲手邀请的人自动同意，两个开关的默认值等用户定）。
7. **登录有效期**：Tailscale 默认 180 天，到期静默断线，界面上还显示"已连接"（调研 §0）。Deneb 如果也要有效期，快到期时在设备块上提示，一点就续上，不能静默断线。M2 设计见 §6.8（离到期两周起提示）。
8. **先通后快**：Tailscale 一开始就经中转连上，再在后台悄悄换成直连，用户不用等（调研 §1.4）。场景 1 现在是先等 1.4 秒"正在连接…"再直接连上；改成"先经中转连上，再换直连"能让人立刻可用。改不改场景 1，等确认。
9. **同时在几个局域网的前提**：Tailscale 做不到，是因为所有网络共用同一段地址和一张路由表（调研 §0）。Deneb 要在地址分配上避开冲突，这是技术方案，不影响界面，但决定场景 3 能不能兑现。
10. **免费额度怎么算**（调研 §6.5）：建议按人计、设备不限、受邀还没登录的人不占名额；不要把分组、角色放进付费，也不要按邮箱域名强制判定"商用"。
11. **中转站的成本和信任**（调研 §6.5）：公共中转站谁出钱、有没有大陆节点、用户自带中转站的流量算谁的、共享设备走谁的中转站（建议和分享方同一批）。
12. **Tailscale 用户常踩坑、demo 还没画的状态**（调研 §6.4）：待同意、需要重新登录、连不上的原因句（对方离线 / 登录过期 / 被限制 / 路由器不让直连，各配一个能点的动作）、共享的范围（分了哪几项服务，单向还是双向，卡片上一句"只有他能连你，反过来不行"）、名额满了"+"怎么变、中转站对共享设备也生效的画法、和 Clash 等 TUN 模式共存的提示、几个局域网里有同名设备时怎么区分。M2 补了其中的待同意、需要重新登录、连不上的原因句、同名设备、和 TUN 共存的提示（§6.7、§6.8）；共享的范围、名额满了、中转站对共享设备生效，留给 M3；M3 补了共享的范围和名额满了（§6.11），中转站对共享设备生效等 M4 有了多个中转站再画。

## 13. 和 Tailscale 的差别（调研结论）

依据 `design/research/tailscale.md`（2026-11-07）。Tailscale 的业务逻辑很完整，但普通人用起来有五处卡点，Deneb 正好用画布和拖拽去解：

1. **一个身份，几个局域网同时在线**（场景 3）。Tailscale 一台设备同一时间只能在一个网络里，靠"快速切换账号"；Deneb 不出现"切换账号"。
2. **分享一台设备，拖一下就好**（场景 4）。Tailscale 要求接收方是对方网络的管理员，只能用完整域名访问，链接式共享还是 Beta；Deneb 把设备拖到人身上就分享，对方不用当管理员，也不用先有自己的局域网，默认只看到这一台，一键收回。
3. **用"服务"代替访问规则**（场景 5）。Tailscale 默认全开，收紧要写 JSON、tag、group；Deneb 在每台设备上开关"谁能用哪项服务"，这些词不出现在界面上。
4. **连接状态看得见、修得动**（场景 1、2）。Tailscale 客户端常常只显示"已连接"，排查靠命令行；Deneb 只说"直接连上 / 经中转"和一句原因，缺中转站就拖一个进来，中转站对整个局域网（包括共享来的设备）一样生效。Tailscale 官方中继没有中国大陆节点，Deneb 的公共中转站要有离得近的。
5. **静默失效变成画面上的待办**。登录过期、等待审批在 Tailscale 里常常是静默的；Deneb 让它们出现在画布上（"待同意"的虚线球、"快到期"的小提示），demo 还没画，见 §12 第 6、7 条。

功能取舍（保留 / 简化 / 不做）的逐项判断见调研 §6.1。MVP 不做：子网路由、应用连接器、公网暴露（Funnel）、固定名字服务（Services）和企业合规类功能；往后放：出口节点（"从这里上网"）、小组、拖文件到设备上传文件。

## 14. 网页版（M3）

> **用户 11-10 看过，按推荐定**（总览页 `设计待审总览.html` 第 2、3、5 批；要选的几条都按推荐：后台留着"不在工作室的人"，网页上的"共享给我"留着"不要了"，中转站见 §14.12 文末）。网页版照这一节写在 `web/`（TypeScript），接控制服务器的 `/api/v1`；11-11 补齐了 §6.7、§6.8、§6.11 在网页上的部分（M3-20 到 M3-23，真页面录屏）。依据：实现计划 §2.5、§5，`design/plan/m3/web.md`。主会话 2026-11-08 定：网页版用 TypeScript 写，风格和桌面端一样。

### 14.1 和桌面端一样

- **一份设计变量**：颜色、圆角、阴影、字号、动效时长、设备块和小球的样式，从桌面端抽成 `web/tokens.json`，网页只从这份读；颜色由桌面端的 `cmd/deneb/theme.go` 自动生成，改一处两边都变。
- 侧边栏、标题区、设备块、小球、卡片、托盘、提示条、拖拽的四个状态、避让、动效、用语，全照 §2–§7。每个画面出设计时，和桌面端的截图并排对照。

### 14.2 和桌面端不一样

- **浏览器不进局域网**：画面上没有"这台电脑"，也就没有从它出发的连线，和桌面端"这台电脑还没加进来"时一样。设备第二行写在不在线（"在线""2 小时前在线"），不写"直接连上""经香港中转"，那是某台电脑自己看到的。
- 侧边栏局域网那一行没有暂停开关：暂停是某台电脑自己的事。
- 是浏览器里的一个页面：没有窗口按钮，页面多大画布就多大。窄于 768 时换成手机的样子（§14.6）。

### 14.3 一个网址，按身份显示

| 谁 | 看到什么 | 网页版第几批 |
| --- | --- | --- |
| 没登录 | 邀请落地页、登录、下载 | 第 1 批 |
| 登录了 | 和桌面端一样的侧边栏和局域网画布（§14.4） | 第 1、2 批 |
| 有自己中转站的人 | 侧边栏"设备"下多一行"中转站" | 第 3 批 |
| 局域网拥有者 | 侧边栏多一组"管理<局域网>"，里面是"设备共享"（场景 4 的后台）。我拥有的每个局域网都有，不只设备共享模式的 | 第 3 批 |
| 部署管理员 | 侧边栏最下面多"运营" | 第 4 批 |
| 登录了的每个人 | 侧边栏"设备"一组："我的设备""共享给我""中转站"（§14.11）；设备共享模式的局域网，我只是成员时不在"局域网"那一组，它分给我的设备在"共享给我"里 | 第 5 批 |

### 14.4 没有"这台电脑"的画布

- 画面和桌面端的局域网画布一样：标题、小球叠、"邀请朋友"、设备块、托盘、卡片。**我的设备排在中间**，别人的设备照桌面端的位置分在四周；都能拖，摆放记在这个浏览器里。
- 标题第二行：都在线时"4 个人，5 台设备都在线"（绿点），有不在线的写"4 个人，5 台设备，4 台在线"（灰点）。
- 设备第二行："在线"；不在线时设备块变灰（§3.4），写"2 小时前在线""昨天在线"。待同意、需要重新登录、"主人不让你用"这些照 §6.7、§6.8。
- **我在这个局域网里还没有设备**（刚接受邀请，还没装 Deneb）：中间是"这台电脑"的虚线块，和待同意的设备一样的画法（没有填充，1.5px 我的颜色的虚线，图形半透明），第二行"装上 Deneb 就能加进来"。单击它打开下载卡片（§14.7）。装好、用同一个邮箱登录以后，网页马上收到：虚线块用 Bouncy 填满成实心设备块，名字换成这台电脑的名字，第二行"在线"，提示条"Leo 的 MacBook 加进来了"。
- 拖进拖出、服务开关、谁能用、把设备拖到人身上分享：和桌面端一样（§6.4、§6.11）。11-11 做进网页：托盘里或画布上我的设备往上拖进标题区，小球叠散开，标题区右下那行字说松手会怎样，放到谁身上就只给谁用这一台；卡片里"分享给"（"+"、开放给他的几项、× 收回、撤销）；单击小球是人的卡片；"还能加 N 人"、位置满了时虚线的"邀请朋友"和位置卡片；待同意的设备和人（虚线块、虚线小球、×、侧边栏小蓝点、等同意的局域网）；局域网卡片（单击标题）；把人拖到侧边栏的局域网上就是邀请；登录快到期、过期、主人不让你用（§6.8）；就地改名（§6.9）。
- **网页上的设备共享**（场景 4，M3-14）：侧边栏和网页版一样，多一组"管理工作室"。主区照场景 4："工作室的设备"网格、"成员"行。成员行下面多一组"不在工作室的人"（用户 11-10 看过，留着）：我在别的局域网里认识的人。把设备拖到他身上，就是只给他用这一台，他不进工作室（§2"只给他用这一台"）。位置满了、他又不占我的位置时，拖过去那一行不亮蓝框，松手后设备飞回，那一行写"位置满了"，不摇（定价文档 §1.5）。

### 14.5 邀请落地页和登录

朋友发来的邀请链接在浏览器里打开，新用户的第一站就是它。

- **邀请卡**：浅灰的页面中间一张白卡片（圆角 20，中阴影），和桌面端收到邀请时的卡片一样：邀请人的小球（40px）和"kittors 邀请你加入「周末联机」"，第二行"里面有 3 个人，5 台设备"，下面是成员的小球叠。主要按钮"加入"（胶囊，占满卡片宽）。卡片下面一行灰字说明 Deneb 是什么："装上 Deneb，几个人的电脑就像在同一个家里，能直接互相用。"
- **登录就在这张卡片里**，一步一屏，内容淡入替换，高度平滑过渡（§6.5）：
  1. 点"加入"：卡片换成"用邮箱加入"和一个输入框（圆角 12，浅灰底，聚焦时蓝色描边），按钮"发验证码"。第二行灰字"以后在电脑上登录 Deneb，也用这个邮箱"。
  2. 卡片换成"输入验证码"、第二行"发到了 l***@gmail.com"，下面 6 个格子，输满自动提交，不用再点按钮。输错时格子左右摇一下、清空，下面写"不对，再看看邮件"。
  3. 对了：卡片换成邀请人的小球和我的小球并排，我的小球用 Bouncy 弹进来，写"你加入了「周末联机」"。停 0.8 秒后卡片淡出，网页版的窗口淡入（§14.4），中间是"这台电脑"的虚线块，下载卡片自动打开。
- 这几步只有一个输入框是必须填的（邮箱），验证码只是 6 个格子，不算表单。
- 已经登录的人打开邀请链接：没有登录那两步，点"加入"直接加入。链接过期、已经在里面，就在卡片上用一句话说明，按钮换成"打开周末联机"。

### 14.6 手机

邀请链接常在手机上打开（微信、短信）。Deneb 只有电脑版，手机上能接受邀请、看和管，不能把手机加进去。

- **邀请卡和登录**：同一张卡片，左右各留 16，占满屏宽；键盘弹起时卡片上移，输入框和按钮留在键盘上方。
- **局域网**：手机上不用画布，用列表：上面是局域网名字（点它从底部弹出局域网列表切换）、小球叠和第二行；下面按人分组，每组头是小球和名字，下面每台设备一行（40px 的设备块、名字、第二行在不在线），我的组在最上面。单击一行，卡片从底部升起（顶部圆角 20），内容和桌面端卡片一样。
- **下载**：底部浮着一枚和托盘一样的胶囊："Deneb 装在电脑上用。在电脑上打开 deneb.app 就能下载"，右边是"复制链接"。点了以后按钮变成"已复制"，胶囊里的话换成"已复制下载链接，在电脑上打开就行"，3 秒后变回来。和托盘的话跟着手上的东西变一样，不另弹提示条，免得盖住列表。

### 14.7 下载

- 下载卡片和设备卡片同一套（右上角，宽 300）：星形图标和"下载 Deneb"，一句话"装上以后，这台电脑就能用周末联机里的设备"，主要按钮按浏览器认出的系统写"下载 macOS 版"，下面一行灰字"也有 Windows 版、Linux 版"，点开换成三个按钮。
- 点下载：浏览器照常下载，提示条"开始下载了，装好后用 l***@gmail.com 登录"。卡片里多一行"装好打开以后，这台电脑会自己出现在这里"。

### 14.8 管理端的中转站（第 3 批）

按身份看到的不一样（主会话 2026-11-08 定）：

- **公共中转站**：所有人都看得到，只能看：地区、在不在线、离你多远（很快 / 有点慢）、每条连接限速多少，加一句"自动兜底，不用管"。别人用了多少看不到。
- **自己的中转站**（我的服务器）全都能管：
  - "用我自己的服务器"给出一行安装命令，点一下复制；在服务器上跑完，列表里自己冒出"我的服务器（香港）· 刚上线"；没用的命令能收回。
  - 拖到侧边栏的局域网上就加进去，拖出来就拿掉，提示条能撤销（§6.4）。
  - 卡片上看负载：几个人、几台设备在用，带宽，这个月替每个局域网转了多少，在不在线、忙不忙。只有"谁在用、用了多少"，没有"谁和谁连"。
  - 权重不用填数字：几个中转站之间分多少，直接拖分界，或者点"多用 / 少用 / 只当备用"。
  - 谁能用：局域网是拖进拖出；人和设备是踢。卡片"谁在用"里点他的小球就踢掉（小球变灰加斜线，和场景 5"谁能用"同一个动作），再点一下撤销；最近 30 天踢过的列在下面。
- **部署管理员**：单独的"运营"页（§14.9）。

### 14.9 运营页（第 4 批）

只有部署管理员看得到（我们自己运营，或者别人自己部署）。公共中转站在这里管，画面和"自己的中转站"一样：加中转站用同一种一行命令，看负载（几台设备、几个人、带宽、流量）、调权重、踢人。

#### M4-11 调权重：几个中转站之间分多少

服务器的做法（控制线 §16 第 3 条）：一个局域网用几个中转站时，按权重给每台设备挑一个排第一，3:1 大约就是 3/4 的设备先走前一个；权重 0 是备用，别的都用不了才用。用户不用懂权重，只看"多少设备先走哪个"。

- **分配条**：在"我的中转站"井里、格子上面，一条 36 高的圆角条，按份额分成几段，每段一个中转站：段宽就是份额，段里放得下就写"名字 百分比"（"公司机房 75%""上海 25%"）；放不下（比如运营页 10% 那段）只写百分比，指上去时段的上方出一个小牌子写名字。段和段之间是一道竖的把手（6×20 的圆角小条，悬停变蓝，鼠标变成左右箭头）。条下面一行灰字说清是什么意思："直接连不上时，75% 的设备先经公司机房，25% 先经上海；都用不了时，自动经公共中转站"。
- **拖分界**：按住把手左右拖，两边的段一个变宽一个变窄，段里的百分比跟着变，下面那句也跟着变；按 5% 一档吸附，一段最窄 10%（再小就点"只当备用"）。松手才发给服务器（两边各一个 `relay.setWeight`，权重就是百分比，加起来 100）。不弹提示条：拖回去就是撤销，和服务开关一样。
- **点按钮**：卡片里多一段"分到多少"，三个并排的按钮"多用""少用""只当备用"（当前状态的那个按下去的样子）：
  - "多用"：它的份额翻一倍（最多到 90%），别的按比例让出来；"少用"：减半（最少 10%）。分配条的段宽用同一个弹簧（Snappy）变过去，百分比滚过去。
  - "只当备用"：它的段从条里收掉（宽度收到 0，名字淡出），别的段按比例长满；条的最右边多一个虚线描边的小格"上海 · 备用"。下面那句加上"上海只当备用：别的都用不了时才用"。只剩一台在用时，条只有一段"公司机房 100%"。
  - 备用的再点"多用"，回到原来的份额。
  - 卡片里这一段下面一行灰字，说现在怎样："大约 25% 的设备先经它"，备用时"只当备用：别的都用不了时才用它"。
- 只有一台我的中转站（或者只有一台不是备用）时，没有分配条，卡片里也没有"多用""少用"，只有"只当备用"。
- 权重是这台中转站自己的（控制线 §16 第 3 条），不分局域网：一条分配条管我所有的中转站。每个局域网只在它用的那几台之间按这个比例分（见文末"要你定"第 1 条）。

#### M4-12 把中转站拖进局域网

- **拖进去**：按住"我的中转站"里的一格，拿起来的是一枚胶囊（小球加名字），跟着手走；格子原处留一个淡的影子。侧边栏里每个局域网那一行都能接：
  - 移到一行上：那一行亮起蓝色描边（和桌面端拖进侧边栏同一个样子），胶囊右边一行蓝字"松手，工作室就用上它"。
  - 这个局域网已经在用它：那一行不亮，胶囊右边一行灰字"周末联机已经在用了"，松手胶囊飞回格子，不摇、不弹框（§6.2）。
  - 松在别处：胶囊飞回格子。
  - 松在亮的那一行上：胶囊缩小着飞进那一行，那一行淡蓝一下（和新局域网进来时一样），格子里"工作室"的小胶囊弹出来（Bouncy），排在已有的后面。提示"工作室用上了上海 · 撤销"（`relay.add`），只有地址的那台写"周末联机用上了我的服务器 · 撤销"；撤销就是小胶囊缩掉（`relay.remove`）。
- **拖出来**：格子里在用它的局域网小胶囊，按住拖出这一格，就是这个局域网不用它了：拖出格子时胶囊右边写"松手，周末联机就不用它了"，松手后小胶囊缩小淡出，提示"周末联机不用公司机房了 · 撤销"（`relay.remove`）；撤销就弹回来。没拖出格子就松手，弹回原处，什么都不变。
- **单击替代**：卡片里"哪些局域网在用"一排同样的小胶囊，悬停露出"×"，点了和拖出来一样；最后一枚虚线的"+ 局域网"，展开我的局域网，点一个就加进去。
- 公共中转站的格子按住拖，胶囊右边写"公共中转站一直都在，不用拖"，松手飞回去；它没有"哪些局域网在用"的小胶囊。

  - 一进来就把令牌从地址栏拿掉（不留在浏览历史和截图里；这个标签页刷新还认得）。
  - **在要验证码的那个浏览器里**（那一页在等验证码，它在浏览器里应一声）：标题"登录 Deneb"，灰字两行"用 tom@example.com 登录 / 原来的页面也会自己进去"，按钮"登录"。
  - **在别的浏览器、手机里**：标题"在这里登录 Deneb？"，灰字"用 tom@example.com 登录这个浏览器"，按钮"在这里登录"。
  - 两种都要点一下才登录：邮件扫描器替人先打开链接，用不掉它；转发出去的信被别人点开，也不会就这么登录了。
  - 点了：按钮按下去，0.15 秒还没答应就转圈写"正在登录…"；登录了，按钮里一个勾"登录了"，0.6 秒里网页在后台准备好，然后整页淡出、网页淡进来，和输对验证码一样。新账号进"第一页"。
  - **用不了**（用过、过期、后来又发了新码）：标题"这个登录链接用不了了"，下面照服务器的话说，一句一行："已经用过、过期了，或者后来又发了新的验证码。/ 回到登录页再发一封就行。"按钮"回到登录页"。试错太多次也照服务器的话说。连不上服务器："打不开这个登录链接"，按钮"再试一次"。
  - **这个浏览器已经用这个邮箱登录了**（或者链接用不了、人已经登录）：不问，直接进网页，链接留着不用。
  - 页面刚打开、服务器 0.4 秒还没答应，写一行"正在打开登录链接…"（灰色小转圈）；快的时候不出现，问的那一屏淡入。
- **原来那个等验证码的页**：链接在同一个浏览器里登录了，它就自己进去，不用再输码。格子描成绿色，下面打勾"用邮件里的链接登录了"，0.6 秒后淡进网页（要回去的地方照旧）。
  - 它在浏览器的后台时（人在新开的那个标签页里），等人切回来才走这 0.6 秒：一回来先看到那个勾，知道是怎么进去的。
  - 浏览器把后台的标签页冻住了、或者老浏览器收不到消息：切回这一页时它问服务器一次，已经登录了就照样进去，打勾"登录了"。
  - 邀请卡里的登录（§14.5）也一样：链接登录了，邀请卡自己接着加入。

### 14.15 运营后台（M7 第 3 批；用户 11-13 看过，6 件都按推荐定了）

> 用户 11-13 登录网页以后说"我以为这是管理后台呢"，定了要做。现在部署管理员要管服务器，只能上服务器敲 `deneb-control` 的管理命令；网页上的运营页（§14.12 M4-13）只管公共中转站。这一节把命令行能做的搬到网页上，给部署管理员用。服务器的接口归控制线（`design/plan/m7/ops-console-api.md`），11-13 晚网页接上了真接口，页面、演示用的假服务器、录屏脚本一起进了主线（`design/plan/m7/ops-console.md` 第 5 节）。

#### 守的规矩

- **只给部署管理员**：别人的侧边栏里没有这一组，打开这些地址也只看到"没有这个页面"。
- **不超出隐私说明第 9 节**："运营方平时用的管理命令列得出"的那些，网页上才列：人（邮箱、名字、几台设备、位置）、设备和它们的状态、谁在浏览器里登录着、报警、备份、日志的最后一段、公共中转站的负载和流量最多的 5 个人；有人要求时替他注销账号。
  - 不显示：设备报上来的外网地址、本地地址和端口；私钥、令牌、验证码；谁和谁连、传了多少（公共中转站只有总数和前 5 个，照旧）；局域网里有谁、开了什么服务、分给了谁。局域网只有个数（文末第 4 条），只有一处例外：替人注销账号的卡片上，为了问"转给谁"，会出现他建的、还有别人的局域网的名字和最早加入的那个人的名字。
- **每个运营操作都记一笔**（运营记录）：谁、什么时候、对谁、做了什么、结果。删设备、注销账号、让人退出、调位置、设管理员、批准登录、公共中转站上的踢人和调份额，都记。
- **大白话，没有表单味**：一句话说清是什么；能点的是胶囊和链接，不是一排排输入框；危险的事红字、要再确认。
- **样子和网页别的页面一样**（用户 11-13 看中间稿时指出，改了）：
  - 整个主区域白底，卡片是白底上的圆角块，和中转站页的井一样；不铺灰底，标题区下面没有横贯的硬边。
  - 内容从标题的左边开始（离左边 28），和中转站页的井对齐，不居中。
  - 一个人、一台设备的卡片是窗口自己的卡片（和局域网画布上设备的卡片一样，从右上角长出来）；它打开时，列表往左让出位置，卡片不盖住任何一行。

#### 侧边栏

- 部署管理员的侧边栏最下面，原来"部署"一组只有"运营"一行，现在是五行：
  - **概况**（脉搏图标）：有要看的报警时，这一行后面一个红点；
  - **用户**、**设备**；
  - **公共中转站**（原来的"运营"页，§14.12 M4-13，只是标题跟着改成"公共中转站"）；
  - **记录**：运营记录和服务器日志。
- 地址：`/ops`、`/ops/people`、`/ops/devices`、`/ops/relays`、`/ops/log`，就在网页里，登录方式和网页一样（文末第 1 条）。

   - 注销账号要输他的邮箱，服务器也要核对 `confirm`；
   - 删设备、设和撤部署管理员，要再点一下；
   - 其余（让设备重新登录、让人在浏览器里退出、调位置上限）不确认，做完提示条写清楚；调位置上限能撤销。
3. **日志**：今天和昨天的；用 `before` 往前翻，最多 2000 行；能按种类筛。更早的到服务器上用命令看。
4. **局域网**：只给个数（一共几个、平均几个人、一个人在几个里面），不给名字、成员和服务。
   - 唯一的例外：替人注销账号的卡片上，为了问"转给谁"，会出现他建的、还有别人的局域网的名字，和最早加入的那个人的名字。这是运营后台唯一出现局域网名字和成员名字的地方。
   - 隐私说明第 9 节到时也要写这一句。
5. **运营记录**：留 1 年；只记做了什么，不记打开过谁的卡片。
6. **替人注销账号以后告诉本人**：给他发一封信："应你的要求，你的 Deneb 账号注销了"，信里不写是谁操作的。

## 15. 品牌（2026-11-13 第三版：小星）

11-13 用户说第二版（一颗亮星，第 3 批）"很丑、没有设计感"，菜单栏和 Windows 的也丑，Windows 的要彩色。第 4 批出了三个方向（`design/brand/batch4/`，桌面 `品牌/第4批-重做/`），用户选了 C："我觉得C挺好的"。细化后换进客户端和网页（桌面 `品牌/第5批-定稿换进代码/`）。

全套文件在 `design/brand/final/`。第二版留在 `design/brand/v2/`（连同它的出图脚本 `v2/tools/`），第一版在 `v1/`，第 1 批在 `batch1/`。标志的画法在 `design/brand/c.py`，`design/brand/build-final.sh`（调 `final_c.py`）出全套，并把客户端要用的文件拷进 `cmd/deneb/`。

### 15.1 标志的意思

- 还是 Deneb 这颗星（天鹅座最亮的星，天津四），变成一个软软的小家伙：品牌蓝、圆润，只有一双眼睛，没有嘴。普通人一眼就喜欢，有性格。
- 竖的光芒比横的长，43 比 36。第一版起这颗星就是竖长横短，这一点留着，它像一颗"站着的"星，不是随便哪颗带眼睛的星。
- 质感就是界面里设备块那种"带光泽的彩色小球"（§3.4）：左上亮、右下深，左上一块柔光和一道小高光，底边一道淡淡的反光，正下方一层落影。
- 眼睛是竖的椭圆，深靛色，各带一个白色的高光点，放在星心稍下。
- 只在说"这就是 Deneb"的地方用：应用图标、菜单栏和托盘、侧边栏抬头、首次引导、登录和启动画面、网页的抬头、下载卡片和浏览器标签。

### 15.2 三种状态（菜单栏和托盘一样）

| 状态 | 什么时候 | 样子 |
| --- | --- | --- |
| 连着 | 平时 | 睁着眼 |
| 要你处理 | 有东西待同意、有设备要重新登录、有设备连不上（§7.1） | 右下角多一个点，点外面空一圈；Windows、Linux 的点是橙色 `#ff8a00` |
| 连不了 | 所有局域网都暂停，这台电脑没联网，或者 Deneb 没在跑 | 闭上眼（两道横着的眼皮），整个变淡：菜单栏是一半的透明度，托盘变成灰色。像睡着了，不看颜色也分得清 |

### 15.3 每个尺寸单独画

| 用在 | 画法 |
| --- | --- |
| 48 像素以上的应用图标 | 完整版：软胶质感、高光、反光、落影，椭圆的眼睛带高光点 |
| macOS 应用图标 16、32 像素 | 浅底方块里一颗平涂的蓝星，上浅下深，眼睛落在整像素上：16 像素是 1×2，32 像素是 2×3 |
| Windows 应用图标 16、24、32 像素 | 没有底板，就是托盘那颗星，深色的眼睛 |
| 菜单栏 | 单色模板图，18 像素和 36 像素（两倍屏）各画一张，合成一个 TIFF，系统按屏幕挑；眼睛镂空，18 像素时 2×3，36 像素时 4×6（两头圆） |
| Windows、Linux 托盘 | 彩色：16、20、24、32 像素（100%、125%、150%、200% 缩放）各画一张，深色、浅色任务栏各一版；眼睛镂空，透出任务栏的颜色（深色任务栏上是深色的眼睛，浅色上是浅色的） |
| 界面里的星 | 单色：`starGlyph`（18 单位，16 到 40 点：侧边栏抬头、首次引导，眼睛落在整点上，两头圆）、`markGlyph`（完整的形，48 点以上：登录和启动画面）；网页的 `G.star`、`star()` 和 `starGlyph` 是同一条路径 |
| 浏览器标签 | 16 像素那颗彩色的星，眼睛镂空；深色浏览器里换浅一档的蓝 |

- 每个小尺寸的星都以像素的交点为中心，左右两半落在像素上一样；眼睛、点都按整像素放（`c.py` 的 `GRID`）。
- macOS 菜单栏仍是单色模板图（苹果的规范）：macOS 26 起菜单栏是透明的，跟着壁纸在黑白之间换，点开时还有高亮，彩色图跟不上。用户同意保持单色。
- Windows 托盘按任务栏深浅（`Tray.Dark`）和托盘所在显示器的缩放挑图，缩放比例在两档之间时用大一档的，系统缩小（`systray.go` 的 `trayIconFor`）。Linux 用深色任务栏那版的 32 像素：GNOME 的顶栏浅色、深色风格下都是深色。

### 15.4 颜色

- 星：品牌蓝的立体渐变，亮处 `#a3c0ff`，主体 `#4a80ff` 到 `#2a5ef0`，暗处 `#1a3fb0`。眼睛 `#0d1a4f`。
- macOS 应用图标的底：浅蓝白 `#f8faff` → `#dfe8ff`，带一层阴影（macOS 27 自己再加一圈玻璃边）。Windows、Linux 的没有底板，星下面一层很淡的落影。
- 托盘：浅色任务栏 `#4f84ff` → `#2152e0`；深色任务栏亮一档，`#8fb3ff` → `#4d80ff`；连不了时灰，浅色任务栏 `#858d9b` → `#626a78`，深色 `#b9bec8` → `#9ba1ac`。
- 单色标志：品牌蓝 `#2f6bff`（深色界面 `#4c82ff`）、纯黑（菜单栏模板图）、纯白（深底、照片上）。

### 15.5 字标和横排组合

- 字标"Deneb"沿用第二版的几何字（`v2/wordmark/`），不是现成字体：界面里用的苹果系统字体不许拿来做 logo。
- 这次没出新的横排组合。要用时照第二版的规矩：标志的高是字标大写字母高的 1.6 倍，竖直对着大写字母的中线，和 D 之间空 0.4 个大写字母高。网页抬头现在是 18 像素的星加界面字体的"Deneb"，不算横排组合。

### 15.6 留白和大小

- macOS 应用图标：1024 画布中间 824 的圆角方块（四周 100 留给阴影和系统的玻璃边），星的 100 单位框占方块宽的 0.8。Windows、Linux 的星占画布的 0.98。
- 标志四周至少留出星高的四分之一。最小 16 像素。

### 15.7 不能怎么用

- 不拉伸、不压扁、不旋转，竖横比例不改；不加嘴、腮红、手脚、表情符号，不换眼睛的样子（只有睁眼和"连不了"的闭眼）。
- 不换颜色：彩色只有品牌蓝这一套；单色只用品牌蓝、纯黑、纯白。
- 应用图标不另加边框、角标、"Beta"字样；底上不加星点、光斑。
- 不放在看不清的底上：深底和照片上用白色单色。
