# Deneb logo 第 4 批：重做（2026-11-13，等用户选方向）

用户 11-13 的原话："我们的项目的 logo很丑，没有设计感，macos的状态栏以及windows的logo都很丑，windows的logo得要彩色的"。

参考图是一整墙 App 图标：有体积、有质感（玻璃、渐变、拟物），有性格，不是平面线条。用户一贯的要求是：克制，一个主角做到极致，不堆元素和特效（他批评过"明显过度设计了"）；但也不能做成平面线条（他嫌那样"非常普通、过于AI化"）。要在这两者之间。

这一批出三个方向，交付在 `~/Desktop/Deneb组网demo/品牌/第4批-重做/`。用户选定之前，客户端和网页都不动，DESIGN §15 仍是现行规则。

## 2. 这次的取舍

- **三个方向都还是 Deneb 这颗星**，竖的光芒比横的长（46 比 37，从第一版沿用下来）。Deneb 的名字就是这颗星（天津四）；第 1 批里用户选的也是"一颗亮星"。用户嫌的是做法：一颗平面的细四角星放在蓝方块上，和满大街的"AI 按钮"、系统符号 ✦ 一个样。所以这次换的是材质、体积和性格，不换主角。
- **一个主角**：每个方向只有这一颗星，材质不同。不加星点、星座、光斑、文字、角标。
- **有体积**：应用图标里靠光影和材质；菜单栏和托盘里，这个方向的特点也得留下来（A 的两档深浅、B 的镂空、C 的眼睛），小到 16 像素也认得出是谁。
- **每个方向三档画法**：大图（48 像素以上）、小尺寸（16 到 32 像素的应用图标，另画）、菜单栏和托盘（另画）。

## 3. 三个方向

### A · 水晶星（`dir_a.py`）

- **意思**：Deneb 这颗星做成一颗切好的水晶，放在夜空里。
- **画法**：直边的四角星，像宝石一样切成八个面：每道光芒沿中脊分成亮的一半和暗的一半，光从左上来。亮面白到冰蓝，暗面是品牌蓝；中脊上一丝青和粉的色散，八个面交汇的星心是一个小亮点，星把周围的夜空照亮一圈。夜空从上到下 `#0a1a5e → #14339c → #1f4fd6`。直边是有意的：凹弧边的四角星就是"AI 按钮"那个样子。
- **macOS**：824 的圆角方块里，星的 100 单位框占方块宽的 0.72。**Windows**：同一片夜空，圆角方块铺满（留 3%，圆角 22%）。
- **菜单栏**：八个面变成两档透明度（亮面 100%，暗面 42%）。仍是单色模板图，系统染色时深浅保留，单色也看得出立体。
- **托盘**：深色任务栏用白加亮蓝，浅色任务栏用浅蓝加深蓝。
- **三种状态**：连着是水晶星；要你处理时右下角多一个点（点外面空一圈）；连不了时只剩轮廓。
- **要知道**：三个里最稳、最"像一个正经产品"；性格最弱。

### B · 光环（`dir_b.py`）

- **意思**：Deneb 的界面里，两台设备之间的连接画成一根透明玻璃管，管里流着彩色的光，每个人一种颜色（§3.2、§3.5）。这里把那根管子弯成一颗星，管里是四个人的颜色（蓝、紫、粉、青，§3.3 的主人色）：几个人的设备连成一圈。说的就是产品做的事。
- **画法**：一根彩色玻璃棒绕成星形：棒身透着颜色，两边颜色深，中间透亮，左上一道高光。四个尖是 U 形的弯，中间留下的孔正好也是一颗星。颜色沿环流动，按 OKLCH 过渡，粉到青之间不发灰。白瓷底，玻璃在底上投下彩色的影子。
- **Windows**：没有底板，就是这个环（Windows 11 自带的图标多是这样）。
- **菜单栏**：芒是实心的，中间一个星形的孔（小尺寸下管子的两边并在一起，比"环"好认）。
- **托盘**：四色的环；深色任务栏上颜色提亮 18%。
- **三种状态**：连着是实的；要你处理时右下角多一个点；连不了时变成虚线，和界面里"连不上只剩一条灰色虚线"是同一个说法。
- **要知道**：故事最好、最有辨识度、最彩色；16 像素时更像一个彩色的小十字星，32 像素以上才清楚。界面别处没有这么多颜色，图标会是最花的那个。

### C · 小星（`dir_c.py`）

- **意思**：这颗星变成一个软软的小家伙，只有一双眼睛，没有嘴。普通人一眼就喜欢，有性格。
- **画法**：圆润的四角星（竖比横长一点），品牌蓝的软胶质感：左上亮、右下深，左上一块柔光和一道小高光，底边一道淡淡的反光，正下方一层落影；就是界面里设备块那种"带光泽的彩色小球"（§3.4）。浅蓝白的底。
- **Windows**：没有底板，就是这颗星。
- **菜单栏**：实心的星，眼睛是镂空的（1 倍屏上 2×3 像素，落在整像素上）。
- **托盘**：蓝星，眼睛镂空，透出任务栏的颜色：深色任务栏上是深色的眼睛，浅色任务栏上是浅色的眼睛。
- **三种状态**：连着时睁着眼；要你处理时右下角多一个点；连不了时闭上眼（两道向下弯的弧）、变淡变灰，像睡着了。不看颜色也分得清。
- **要知道**：最亲切、最有性格；也离"网络工具"的印象最远。参考图里带眼睛的图标很多，这条路现在很流行。

## 4. macOS 菜单栏为什么还是单色模板图

- 苹果的规范是菜单栏图标用模板图，系统按菜单栏染色。macOS 26 起菜单栏是透明的，跟着壁纸在黑白之间切换，点开时还有高亮；彩色图跟不上这些，花壁纸上会脏。
- 所以这次在规范里面做出区别：A 用两档透明度保住立体，B 中间镂空，C 镂空眼睛。都比现在那颗细四角星有分量。
- 也可以例外：MyGo 支持非模板图，把 Windows 那套彩色图放进菜单栏就行，代价是上面几条。这一条请用户定，推荐保持单色。

## 5. Windows 托盘：彩色

- 每种缩放各出一张：100% 是 16 像素，125% 是 20，150% 是 24，200% 是 32。
- 深浅各一版：Windows 会告诉任务栏是深还是浅（`Tray.Dark`），客户端已经在按它换图。
- "要你处理"的点是橙色 `#ff8a00`，点外面空一圈。
- 连不了：变灰（深色任务栏 `#a3a8b3`，浅色 `#6b7280`），形状也跟着变（A 只剩轮廓、B 变虚线、C 闭眼），不只靠颜色区分。
- Linux 托盘现在只能是白色单色；建议用 Windows 深色任务栏那一版彩色图（GNOME 顶栏是深色的）。

## 6. 小尺寸

- 16、32 像素的 macOS 图标和 16、24、32 像素的 Windows 图标另画一版：A 是两色平涂的星，B 只留四色的环，C 是平涂的蓝星加两个落在整像素上的小眼睛。
- 选定之后再逐像素修：B 的 16 像素，C 在 20、24 像素（不是整数倍缩放）时有点糊。

## 7. 选定之后，换进代码要动的文件

1. 出全套：选中的方向细化后，照第 3 批的样子出到 `design/brand/final/`，现在那版挪到 `design/brand/v2/`；`build-final.sh` 改成调这一批的脚本。
2. 应用图标：换 `cmd/deneb/Deneb.icns`、`icon.png`、`icon-dev.png`。
   - Windows 的 16、24、32 像素：MyGo 打包时从 `icon.png` 自动缩，用不上单独画的小尺寸版。要用上，得让 MyGo 收现成的 `.ico`（改 MyGo 的 `cmd/mygo/icon.go`，上游）；不改就是自动缩，B 在 16 像素差得最多。
3. 菜单栏：`cmd/deneb/trayicons/` 的三张模板图重画，`trayglyph.go` 的路径换掉，跑 `DENEB_TRAY_ICONS=1 go test -run TestTrayIcons ./cmd/deneb`。A 的两档透明度、C 的镂空眼睛、B 的虚线，MyGo 的 SVG 都支持（`fill-opacity`、`mask`、`fill-rule`、`stroke-dasharray`）。
4. Windows 彩色托盘：新放一组 PNG（三种状态 × 深浅 × 16、20、24、32）；改 `systray.go` 的 `trayIconFor()`：Windows 那一支返回彩色图，并按托盘所在显示器的缩放比例挑尺寸。MyGo 的 Windows 托盘只收一张 PNG、按它自己的尺寸建图标，剩下交给系统拉伸，所以挑尺寸得在 Deneb 这边做。`SetIcon` 在 Windows 上传的本来就是非模板图，彩色图不会被染白。Linux 那一支同样换成彩色（如果用户同意）。
5. 界面里的星：`glyphs.go` 的 `starGlyph`、`markGlyph` 换成新形状；`traytip.go` 跟着变。登录和启动画面 52 点那颗可以用彩色版（`ui.Image` 能画渐变）；C 要定界面里的星带不带眼睛（建议登录画面带，侧边栏 18 点不带）。
6. 网页：`web/app/index.html` 的小图标（16 像素版和深色版都要），`v3-glyphs.ts` 的 `G.star`，`download.ts` 的 `star()`；重新构建 `web/app/dist`。
7. 测试：`TestTrayIcons`，和托盘、菜单栏、视图相关的那十几个测试；`go vet ./cmd/deneb` 在 darwin、windows、linux 下都过。
8. 文档：重写 DESIGN §15，改 §7.1、§7.2 里图标的描述（三种状态的新画法、Windows 彩色）。
9. 客户端线的登录页、验证码邮件、网页空状态：换成新标志（邮件用 PNG）。
