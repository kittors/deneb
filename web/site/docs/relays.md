# 中转站

两台设备无法直接连接时（比如都在公司或学校的网络后面），Deneb 会经一台服务器转发，这台服务器就是中转站。转发的内容是加密的，中转站无法解密。

![连线上写着直接连上、经香港中转](relay-line)

- 线上写「直接连上」，表示没有经过中转站；写「经香港中转」，表示经香港那台。
- 公共中转站由 Deneb 提供，自动使用。

## 用自己的服务器做中转站

1. 点托盘最后的「+」（用我自己的服务器当中转站），在卡片里复制那一行命令。
   ![托盘最后的「+」](relays-plus)
2. 在服务器上运行这行命令。装好以后，托盘写「我的服务器刚上线，拖进来就能用」。
3. 把它拖进局域网，这个局域网就使用它。
   ![局域网用上了自己的服务器](own-relay)
