# 把一台设备分享给朋友

只把一台设备给某个人用：对方不必加入你的局域网，只能看到这台设备。

1. 打开局域网，把你的一台设备拖到右上角朋友的头像上，看到「松手，只给 Mia 用这一台」时松手。
   ![把我的 NAS 拖到 Mia 的头像上](share)
2. 对方的头像弹一下，提示条写「已把我的 NAS 分享给 Mia」，可以撤销。
3. 修改开放哪些服务：点对方的头像，在卡片的「开放给 Mia 的」里逐项打开或关闭。
   ![Mia 的卡片：分享给她的设备和开放给她的服务](share-card)
4. 收回：点这台设备，把指针移到卡片「分享给」里对方的名字上，点右上角的「×」。提示条上可以撤销。
