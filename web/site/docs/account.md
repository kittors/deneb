# 账号和隐私

登出、删除一台设备、注销账号。

## 登出

1. 点侧边栏左下角的头像，打开账号卡片。
2. 点「登出」。再登录时，用同一个邮箱。
   ![账号卡片](account-card)

## 删除一台设备

1. 在「我的设备」里点那台设备的「详情」。
2. 点最下面的「删除这台设备」（这台电脑写「删除这台电脑」），在对话框里点「确认删除设备」。它会退出所有局域网、收回给别人的分享并登出。提示条上可以撤销。
   ![删除这台设备](account-delete-device)

## 注销账号

1. 点侧边栏左下角头像旁的设置按钮，选「注销账号」。
2. 页面列出会删掉的东西。你建的局域网里还有别人时，选「转给最早加入的人」或「整个删掉」。
3. 再输一遍邮箱，确认注销。注销后不能恢复。
   ![注销账号：会删掉的内容](account-delete)

> 我们收集什么、不收集什么，见[隐私说明](https://github.com/kittors/deneb/blob/main/PRIVACY.md)。
