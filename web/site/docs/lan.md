# 新建局域网、邀请朋友

同一个局域网里的设备可以互相访问。可以只放自己的设备，也可以邀请朋友。

1. 点侧边栏的「新建局域网」。新局域网先只有这台电脑。
2. 把你的设备从托盘拖到画布上。
   ![从托盘把设备拖进局域网](lan-drag)
3. 点右上角的「邀请朋友」，邀请链接会复制好，发给朋友。对方在浏览器中打开，用邮箱加入。
   ![右上角的「邀请朋友」，下面是还能加几人](lan-invite)
4. 需要你同意才能加入：点标题区的局域网名称，在局域网卡片的「加入审批」里打开「审批新成员」「审批新设备」。
   ![局域网卡片：加入审批](lan-card)

> 你建的局域网里，每人占一个位置。位置用完时，「邀请朋友」变成虚线，点它可以查看谁占着位置。
