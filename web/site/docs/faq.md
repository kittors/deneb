# 常见问题

装不上、连不上、安全吗，以及手机上能做什么。

## 首次打开时被系统阻止？

见[安装](/docs/install)第 3 步，放行一次即可。

## 手机能用吗？

在手机浏览器中打开 deneb.app，可以接受邀请、查看谁在线。手机本身不能加入局域网。

## 安全吗？

设备之间端到端加密，能直接连接时不经过我们的服务器；经中转站转发的内容也是加密的。详见[隐私说明](https://github.com/kittors/deneb/blob/main/PRIVACY.md)。

## 无法连接怎么办？

先看那台设备是否在线；这台电脑没联网时，标题下面会写出来。其他情况下，Deneb 会自动经中转站连接。仍然不行：在局域网画布上点这台电脑，在卡片里展开「更多」，点「导出诊断包」，诊断包存到「下载」，把它附在 [GitHub](https://github.com/kittors/deneb/issues) 的问题里。

![这台电脑的卡片：更多、导出诊断包](faq-diag)

## 开着代理软件？

Surge、Clash 这类代理软件可能挡住连接。Deneb 认出它们时，标题区会出现提示，比如「Surge 可能挡住连接」；点开，按说明把那一条规则加进代理软件。

![Surge 可能挡住连接：加一条规则](faq-proxy)

## 怎么删除设备、注销账号？

见[账号和隐私](/docs/account)。
