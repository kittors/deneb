# 开放服务

远程桌面、共享文件夹、网站等服务，可以分别开放给不同的局域网。

1. 打开「我的设备」，找到那台设备的「服务」一行。
2. 每项服务后面是这台设备所在的局域网：点虚线的局域网名称，即开放给这个局域网；点带勾的，再点一下确认，即关闭。
   ![服务分别开放给不同的局域网](services)
3. 添加服务：点「添加服务」，填写名称和端口。端口是那个程序使用的号码，比如网站常用 8080。
   ![添加服务：名称和端口](services-add)
4. 其他人怎么使用：在局域网画布上点你的设备，再点服务旁的「打开」。
   ![设备卡片里服务旁的「打开」](services-open)

> 开放命令行后，对方可以经这台电脑访问其他地方，请只开放给信任的人。
