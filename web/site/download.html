Linux

窗口和后台服务两个包一起安装。在下载目录中运行：

sudo apt install ./deneb.deb ./denebd.deb

ARM64 换成 deneb-arm64.deb、denebd-arm64.deb。没有屏幕的服务器装 deneb-server.deb。

Mac
打开「系统设置」>「隐私与安全」，在「安全性」中点按「仍要打开」，再输入登录密码。
Windows
出现「Windows 已保护你的电脑」时，点「更多信息」，再点「仍要运行」。
